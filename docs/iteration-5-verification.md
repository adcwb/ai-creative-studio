## 回归过程中发现与修正

- 旧剧本回归使用 `.drama-generation` 选择器；第五轮新增分镜生成区域后，该选择器匹配两个区域。主集成将 `scripts/project_check.mjs` 与 `frontend/e2e/project.spec.ts` 改为精确可访问区域名称“生成模拟剧本”，保持原失败码断言与验收语义。
- 早期图像布局运行曾有 Go PATH 配置失败，修正环境后又在并发负载期间遇到 `.template-card` 加载超时；这些失败不计为通过，后续串行重跑。
- Provider 首轮在持续编辑/并发检查期间遇到能力禁用断言失败；完整重跑通过，证据 `/tmp/studio-provider-evidence-UEzMJi`，5 次本地假上游调用，重放未额外调用。没有发往真实付费服务。

- 首次完整串行 E2E 为35/36通过，全部8项分镜测试通过。旧图像首项在读取 templates 响应体时出现 Chromium `Network.getResponseBody: No data found for resource with given identifier`；未修改该测试或降低断言，重新完整执行。此错误不能据局部通过日志忽略。

- 第二次完整执行中，旧项目错误恢复测试暴露拦截安装竞态：切回空间可立即自动加载最新项目，之后注册故障拦截可能错过请求。trace 显示项目已正常加载、预期重试按钮不存在。将拦截安装提前至切空间之前，保持原错误恢复断言；第二次完整执行仍为35/36通过（全部分镜通过）；测试修正后仅重跑受影响用例的桌面/手机两项，不重复已经有效通过的其他检查。

## 新增验收路径

- 从已保存剧本生成分镜；快速双击仅创建一个后端尝试。取消编辑不写后端，保存成功后刷新仍可读取。
- 保存已提交而响应丢失时，保留本地草稿和原 body/key，重试返回原操作而不重复增版。
- 已保存剧本修改使分镜过期；编辑旧分镜不消除过期；取消重新生成不创建尝试；模拟生成失败保持旧计划、来源与版本。
- 另一客户端先保存后，陈旧保存返回 409 并保留本地输入；项目、空间、工作台切换均要求明确放弃；取消确认或 Escape 保留草稿。
- 无剧本不能发起分镜；空画面描述禁用保存，不向后端提交无效编辑。
- 真实进程重启检查覆盖 running 恢复及后端幂等记录，不以浏览器刷新代替进程恢复。
