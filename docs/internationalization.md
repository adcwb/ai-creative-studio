# 界面语言与显示格式

前端目前支持 `zh-CN` 与 `en`。登录页和工作区提供语言选择，保存至浏览器 `studio.locale`；存储被禁用时仍可在当前会话切换。无有效偏好时使用浏览器首选语言：中文变体使用简体中文，其余语言回退英文。`html.lang` 随首次选择及后续切换更新。

`frontend/src/i18n.ts` 提供 `useI18n()`、`translate()` 与具名插值。字典按领域位于 `frontend/src/locales/`；中文原文作为消息键，英文作为值，未知键保留原文。组件订阅语言 context 后渲染消息，不用扫描或替换 DOM。新增语言应扩展 Locale、resolveLocale、字典选择与 LanguagePicker，并补浏览器测试。API 错误按稳定错误码翻译；项目标题、创作内容、服务端历史文本与用户上传文件名保持原文，不自动翻译用户资料。

日期、数字和金额使用 Intl 的当前界面 locale；金额格式器默认币种 USD，也可显式传入服务端币种。界面语言不会改变账本币种、金额、模型或供应商配置，也不执行汇率换算。当前主要创作流程没有金额交易表单；真实费用和汇率不能由界面显示值推定。

语言单元测试覆盖浏览器回退、持久选择优先、具名插值与币种解耦。桌面/手机实际布局和浏览器回归结果见本轮交付矩阵；新增英文长文本仍须纳入这些检查。

运行 `node scripts/i18n_check.cjs` 可检查所有静态 `t/translate` 中文消息键都有英文值，并拒绝未提取的中文 JSX 文本（语言选择中的本地名称除外）。它不替代动态供应商错误、历史内容、真实屏幕阅读器或英文布局验收。
