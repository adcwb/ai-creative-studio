仓库此前没有独立 roadmap 文件，路线位于 `docs/architecture.md` 的“后续适配路径”：项目 → 创意分析 → 剧本 → 分镜 → 角色一致性资产 → 音视频生成 → 合成。本轮选择该路径首段，而非同时引入生产基础设施与视频功能。
