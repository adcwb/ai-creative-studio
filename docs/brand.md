# 映创 · 品牌与界面规范

映创是一间安静、清晰的视觉工作室。界面以深绿提供方向感，用暖白承载创作内容；文字直接说明真实状态，不把模拟图像包装为真实 AI 输出。

## 原创标记

本轮手工绘制的“映窗”标记由两扇纵向画框和一道向右投射的负形光束组成，表达从想法到画面的过程。几何图形由代码绘制，没有使用生成模型、外部图标品牌或位图。标记适合小尺寸使用，应用内至少显示 24px，浏览器 favicon 使用同一 SVG。

- `frontend/public/brand/mark.svg`：独立标记，暖白与深色背景均可使用，也是 favicon 的实际源文件。
- `frontend/public/brand/lockup-light.svg`：用于暖白背景的标记与“映创 / CREATIVE STUDIO”组合。
- `frontend/public/brand/lockup-dark.svg`：用于深绿背景的浅色组合，应用侧栏使用此文件。

标记四周至少保留自身宽度四分之一的留白。组合字标采用本机中文无衬线字体，不加载外部字体；字标最小宽度为 118px。不旋转、拉伸或添加投影。界面图标采用统一的手工 SVG 线条。

## 界面原则

颜色、字体、间距、圆角、阴影与状态由 `frontend/src/tokens.css` 中的 CSS 自定义属性统一管理，`frontend/src/style.css` 定义组件布局和断点。主色深绿、辅助色鼠尾草绿与暖白，失败状态为深砖红，提示状态为赭色。界面无需装饰性渐变，强调真实内容与交互层级。

| 规范 | 当前值 | 用途 |
| --- | --- | --- |
| 品牌深绿 | `--primary: #244b3b` / `--forest: #193b2e` | 主操作 / 侧栏 |
| 画布与内容 | `--canvas: #f7f7f2` / `--surface: #ffffff` | 暖白背景 / 面板 |
| 正文与次级文字 | `--ink: #263e32` / `--ink-muted: #63705e` | 内容与辅助说明；占位文字使用相同深度 |
| 点缀色 | `--accent: #d9e4b5` / `--green-soft: #617b50` | 深色字标、进度与装饰 |
| 成功状态 | `#edf3e5` 背景 / `#4d6940` 文字 | 保存确认与完成任务 |
| 提示状态 | `#f6f2e7` 背景 / `#7c6940` 文字 | 演示说明、排队与重试编辑 |
| 错误状态 | `#fff1ec` 背景 / `#a54837` 文字 | 后端失败与请求错误 |
| 焦点 | `--focus: #ad853b`，3px 外描边 | 键盘定位 |
| 字体 | PingFang SC、Microsoft YaHei、system-ui | 无外部字体请求；数字装饰使用 Georgia；普通辅助文本 11–12px，8px 仅用于英文眉题 |
| 间距 | 4、8、12、16、20、24、32px | 控件、组与面板节奏 |
| 圆角 | 8、10、14px；胶囊 999px | 控件、卡片、面板与徽标 |
| 阴影 | 轻微面板阴影、悬停阴影、模态阴影 | 分层，不用于正文装饰 |
| 响应式 | 1240px / 1050px / 700px | 收紧侧栏与边距 / 创作单列 / 顶部空间栏与移动布局 |

常用颜色已按 sRGB 相对亮度核算：次级文字在暖白画布上约 4.87:1；绿色素材标识在白底上约 4.71:1；成功、提示、错误文字在各自背景上分别约 5.44:1、4.75:1、5.32:1；焦点描边对白底约 3.39:1、对深绿侧栏约 3.63:1。这是针对常用配色的检查，不等于完整无障碍认证。

桌面采用覆盖整页的侧栏背景轨道与工作画布，侧栏内容在足够高的视口中随滚动保持可见。创作区将设置和记录并排等高排列，按照实际内容自然延展；窄屏按内容顺序折叠，避免横向滚动。短屏侧栏内容随文档滚动，不裁切操作。模板、控件、任务操作与筛选均可通过键盘完成。对话框使用原生 `dialog` 的模态焦点范围，支持 Escape 与关闭按钮，并将焦点还给触发控件。

可操作的模板、参数、任务、重试和素材查询必须接入实际后端。加载、空数据、查询无结果和服务错误分别呈现。短剧工作台提供真实项目、简报、异步生成和剧本保存 API，文本来源明确标注为 `mock-script` 程序生成的模拟剧本；不使用图像提供方标签暗示真实文本模型。分镜、音视频、合成和导出尚未提供，不出现可点击的占位功能。

当前服务状态由后端能力接口驱动；“真实图像服务 · 配置就绪”只描述本地配置，不代表远端凭据或画质已验证。所有模拟结果始终标注“模拟图像 · 非 AI 生成”；真实 provider 结果标注“OpenAI 图像服务返回”，根据每条历史记录的来源区分，不能随当前模式改写旧图标签。演示空间用于整理数据，不代表认证或企业权限隔离。
