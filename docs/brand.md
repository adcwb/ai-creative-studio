# 映创 · 品牌与界面规范

映创是一间安静、清晰的视觉工作室。界面以深绿提供方向感，默认用墨绿暗画布承载创作内容，让图像与分镜成为主角；另备一套暖白工作室供明亮环境长时间阅读。文字直接说明真实状态，不把模拟图像包装为真实 AI 输出。

## 原创标记

本轮手工绘制的“映窗”标记由两扇纵向画框和一道向右投射的负形光束组成，表达从想法到画面的过程。几何图形由代码绘制，没有使用生成模型、外部图标品牌或位图。标记适合小尺寸使用，应用内至少显示 24px，浏览器 favicon 使用同一 SVG。

- `frontend/public/brand/mark.svg`：独立标记，暖白与深色背景均可使用，也是 favicon 的实际源文件。
- `frontend/public/brand/lockup-light.svg`：用于暖白背景的标记与“映创 / CREATIVE STUDIO”组合。
- `frontend/public/brand/lockup-dark.svg`：用于深绿背景的浅色组合，应用侧栏使用此文件。

标记四周至少保留自身宽度四分之一的留白。组合字标采用本机中文无衬线字体，不加载外部字体；字标最小宽度为 118px。不旋转、拉伸或添加投影。界面图标采用统一的手工 SVG 线条。

## 界面原则

色值的唯一来源是 `frontend/src/ui/palettes.ts`。它同时派生 antd 的 `ConfigProvider` token 与运行时注入的 CSS 自定义属性，两者不再各写一份、也不会漂移。`frontend/src/tokens.css` 只保留字体、字号、间距、圆角等非颜色令牌，`frontend/src/style.css` 定义组件布局与断点。组件级外观差异通过 `theme.components` 表达，不用全局 CSS 覆盖 `.ant-*`。

主色深绿、辅助色鼠尾草绿，失败状态为砖红，提示状态为赭色。界面无需装饰性渐变，强调真实内容与交互层级。

主题只有两套：**暗房**（默认）与**工作室**。原「森林工作室 / 暖纸画廊 / 深色放映室」三套已下线，旧偏好按 forest、paper → 工作室，screening → 暗房 迁移，新账号默认暗房。

对比度按 sRGB 相对亮度核算，并由 `frontend/src/ui/palettes.test.ts` 在每次单测中强制：文字不低于 4.5:1，控件边界、焦点环、光轨与图标不低于 3:1。暗房实测正文对面板 14.51:1、次级字 7.81:1、白字对主色 4.99:1、控件边界对面板 3.63:1、焦点环对侧栏 10.00:1；工作室实测正文对画布 10.75:1、次级字 4.87:1、白字对主色 9.79:1、控件边界对白底 3.51:1、焦点环对深绿侧栏 3.37:1。这是针对令牌配对的检查，不等于完整无障碍认证。

工作室的焦点色本轮由 `#8a651f` 调整为 `#a97f2a`：原值对白底 5.30:1 达标，但对深绿侧栏只有 2.32:1，低于 3:1 门槛（旧文档记录的 `#ad853b` 才对应 3.63:1，说明令牌与文档此前已经不一致）。新值对白底 3.65:1、对画布 3.39:1、对侧栏 3.37:1，三处同时达标。

桌面采用覆盖整页的侧栏背景轨道与工作画布，侧栏内容在足够高的视口中随滚动保持可见。创作区将设置和记录并排等高排列，按照实际内容自然延展；窄屏按内容顺序折叠，避免横向滚动。短屏侧栏内容随文档滚动，不裁切操作。模板、控件、任务操作与筛选均可通过键盘完成。对话框使用原生 `dialog` 的模态焦点范围，支持 Escape 与关闭按钮，并将焦点还给触发控件。

可操作的模板、参数、任务、重试和素材查询必须接入实际后端。加载、空数据、查询无结果和服务错误分别呈现。短剧工作台提供真实项目、简报、异步生成和剧本保存 API，文本来源明确标注为 `mock-script` 程序生成的模拟剧本；不使用图像提供方标签暗示真实文本模型。分镜计划明确标注 `mock-storyboard`，支持真实保存与来源过期提示；分镜图像、音视频、合成和导出尚未提供，不出现可点击的占位功能。

当前服务状态由后端能力接口驱动；“真实图像服务 · 配置就绪”只描述本地配置，不代表远端凭据或画质已验证。所有模拟结果始终标注“模拟图像 · 非 AI 生成”；真实 provider 结果标注“OpenAI 图像服务返回”，根据每条历史记录的来源区分，不能随当前模式改写旧图标签。演示空间用于整理数据，不代表认证或企业权限隔离。
