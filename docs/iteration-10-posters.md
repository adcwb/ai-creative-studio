# Editable poster layers

A project now stores one editable poster document alongside its media state. Chinese and English UI supports text and owned PNG/JPEG logo layers, pixel positions and rectangular bounds, opacity, color, font size and layer order. Canvas dimensions are 256–2048 pixels per side; at most 12 layers. Text supports 1–300 Unicode characters and at most nine lines. Text is clipped to its rectangle; logos retain aspect ratio at the rectangle's top left. Logo upload uses the existing validated media upload flow.

`PUT /api/v1/projects/{id}/media/poster` accepts `expected_version` and `poster`. `POST .../poster/exports` renders the exact saved version into a PNG and appends a downloadable `MediaAsset` with source `poster-composite`. Both require existing media idempotency keys, tenant/project authorization, role/CSRF checks and media version CAS. Saved poster metadata participates in existing file/PostgreSQL persistence and backups; PNGs use the configured media BlobStore. A successful retry returns the existing export instead of adding another asset.

Rendering uses bounded local FFmpeg, not a provider or browser screenshot. User text goes into a private text file with drawtext expansion disabled, not into filter syntax. External image URLs, arbitrary fonts/filter expressions and cross-project assets are rejected. Each render is limited to 30 seconds, 4 megapixels and the existing 32 MiB media asset limit. The media transaction remains locked during rendering to bind output to the accepted saved version; high-volume parallel poster production is not promised. The browser retries an uncertain response using the original request key. Explicit validation/version errors preserve edits for correction or deliberate reload.

Preview uses browser fonts; export uses the server's installed sans font and glyph coverage. Typography is approximate until the final PNG is reviewed. There is no font upload, SVG/HTML layer execution, rich typography, transform rotation or professional print/CMYK workflow. Browser language switching does not change stored poster copy. Old binaries can ignore new poster metadata: rollback requires a matching stopped backup, not a claim of lossless downgrade.

`TestPosterSaveExportReplayIsolation` verifies actual decoded PNG dimensions, background/logo/text pixels, literal filter-like text, version conflict, replay and cross-project/tenant artifact isolation. `TestPosterValidation` covers unsupported dimensions, injection-like colors, control characters and out-of-canvas layers. Independent browser acceptance covers Chinese/English desktop/mobile save/export/reload. These are local synthetic tests, not model or social publication evidence.
