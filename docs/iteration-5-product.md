# 第五轮最小验收：可编辑分镜计划

从已保存剧本创建一份当前分镜计划，用户可以查看、逐镜编辑并真实保存。生成明确是 `mock-storyboard` 程序模拟，前后端和持久化真实运行。没有新增音视频、角色资产、素材衔接、完整剪辑器或历史版本回滚。

1. 无项目、未保存剧本、无分镜时分别说明下一步；未保存的需求或剧本不能冒充生成来源。
2. 异步生成显示等待、执行、成功或失败；离开页面不取消已经接受的后端任务。
3. 当前计划展示场景位置、画面描述、景别、运镜、时长与对白，支持编辑保存；成功提示只在后端确认后出现。
4. 源剧本更新后显示计划过期；修改项目需求不等于修改剧本。继续编辑旧计划仍保留过期提示。
5. 已有计划重新生成需确认；失败保留旧计划。活动生成阻止冲突写入，服务端版本校验是最终依据。
6. 保存冲突、读取失败和结果不明可恢复；草稿与原请求幂等信息保留，不静默覆盖。切换项目、空间或工作台继续采用未保存修改保护。
7. 刷新、服务重启后读取相同已保存记录；生成恢复及幂等重放不重复增加版本。
8. 回归图像与剧本流程、桌面底部对齐、短屏可达性、移动端单列和长文本无横向溢出。

接口支持有界完整镜头数组，界面范围是编辑已生成镜头，不要求自由增删、拖拽排序或时间轴。字段与版本语义以 [第五轮架构](iteration-5-architecture.md) 和 [OpenAPI](../api/openapi.json) 为准。
