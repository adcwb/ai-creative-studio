## 范围与创作者流程

用户从空个人空间进入工作室时，应能理解团队旧作品和模型配置没有丢失，并主动进入已有团队空间。选择灵感模板只填写描述和参数；模型能力是管理员声明，不能把配置满足、目录连接成功或合成测试表述为真实能力/效果验收。新创作继续使用真实网关链路，历史模拟记录保留其真实来源。

本轮保留生产deepseek-v4-pro的8类测试勾选，不修改任何生产数据或模型配置；不调用付费模型。暂停分支`work`的`02638f2`及其父提交完整保留，仅择取该提交中的9:16参数、目录、请求尺寸、提示词及对应测试，不引入其系列默认值联动或其他短剧增量。

## 可测试验收标准

- C01：登录用户的个人空间无创作记录且有可访问团队时，展示个人/团队数据独立的解释、团队选择和明确切换按钮。只列会话有权访问的空间，不自动切换、不复制或移动作品/模型配置；无团队时不暗示已有团队。切换沿用工作区权限与离开确认机制。
- C02：生产网关入口显示网关创作语义，素材、设置等页面显示当前空间语义，不把进程的旧mock图像适配器当作这些页面的服务状态。历史mock-svg仍显示“模拟图像·非AI生成”，不重写来源、文件或记录。显式本地legacy-fixtures演示设施保留真实模拟说明。内置模板明确只是提示词与参数，不是已经生成的作品；肖像模板不再误称只能模拟。
- C03：侧栏品牌、空间选择和底部设置入口固定，中部菜单独立滚动。展开的长菜单文字可换行阅读；收起的图标仍有可访问名称。1920×1080、1366×768、390×844无页面横向溢出；手机保留抽屉、Escape和焦点恢复。截图发现提示词来源按钮在手机被均分为过窄列，已改成可换行的合理宽度，并断言按钮不会压成竖排长条。
- C04：原“可执行/Ready to execute”改为“配置就绪/Configuration ready”，解释本地配置检查不代表已验证上游凭据、能力或生成效果。模型能力标签继续原样显示，不自动删改任何勾选，不增加自动付费测试或新准入门槛。
- C05：图像创作、提示词默认参数及项目/镜头图像比例可选9:16；前后端校验、目录和OpenAPI一致。通用网关请求尺寸为864×1536，原生支持aspect ratio的适配器传9:16；保留上游实际返回像素，不伪造尺寸或静默裁切。模型可能拒绝不支持的尺寸，沿用明确错误与无模拟回退。旧1:1、4:5、16:9、缺省参数及既有文件保持兼容。
- C06：相关前后端测试、构建与真实截图完成；合成上游只用于协议和恢复测试，不作为真实模型质量或供应商授权验收。规范、证据与代码同属本地审查提交。

## 实现映射与兼容

`SpaceGuidance`复用已有WorkspaceContext和空间目录，图像与独立短剧空状态挂载，无新增数据表或API。`StudioShell`将菜单滚动与页头/页脚分开，保留既有森林/纸白/深色变量。模型状态只改呈现，不改路由或能力过滤逻辑；已有RBAC、租户、凭据和内容审核模式保持不变。

9:16贯穿generation.Normalize、prompts.NormalizeRecipe、Catalog、imageSize、前端Ratio及参数下拉框；OpenAPI枚举同步。模拟画布支持仅供合成测试/旧显式演示，不向生产创作新增模拟回退。无数据库迁移，无历史数据重绘。旧数据向前兼容；实际保存9:16后若回退至不支持此枚举的旧版本，须使用匹配版本与备份，不能承诺旧校验器能读取新增比例。
