## 交互与兼容设计

1. 模型摘要是原生 details，其内仍是原来的运行时选择器。已配置可折叠，失效或加载失败强制展开。内容审核停用说明在折叠时仍显示，不能将其呈现成已通过审核。
2. 提示词使用现有桌面 Modal / 手机 Sheet 统一容器，表单滚动区与操作区分离。保存请求、恢复记录及显式放弃确认保持原实现。
3. 模型列表筛选用 hidden 保留行组件与草稿；版本更新仍按服务端版本重新初始化表单。展开状态独立保存在父级，防止保存导致卡片突然收起。
4. 手机工作流把步骤选择提前，但保留流程名称、保存、运行、节点工具与变量定义。展开画布复用同一图状态，不创建第二份流程副本。
5. 剪辑预览与海报保持组件挂载，以免切换可见性丢失已有编辑状态。无素材不显示黑色预览和巨大空画布；用户仍可展开编辑区进行必要操作。
6. 创建团队统一进入 `/settings/spaces`。既有 `/settings/organization` URL 保持有效，页面明确展示当前空间成员与权限。
7. 无 API 或数据库变更，无迁移。回退代码即可恢复旧布局；已有提示词、素材、流程和团队数据不受影响。

## 可测试验收

- **AC-01** Given 已配置且能力匹配的图像模型，When 桌面或手机打开创作页，Then 描述与主按钮在首屏；选择模板仍填入并聚焦描述，展开/收起模型不改描述。Given 未配置模型，Then 原阻断提示保持可见且不能生成。
- **AC-02** Given 提示词编辑弹层，When 表单滚动至底，Then 标题/关闭/保存仍在视口；保存发送原描述、幂等键和现有协议，完成后主描述不丢失。真实后端的版本冲突和断线恢复测试继续通过。
- **AC-03** Given 森林/纸张/放映室，When 主题与页签动画结束，Then 网关状态标签与选中页签文本对比度不低于 4.5:1，状态仍有明确文字。采用主题令牌而非依赖注入样式顺序。
- **AC-04** Given 发布授权面板，Then 复选框宽度不超过 24px，与说明文字同排，保留显式勾选和原授权请求语义。
- **AC-05** Given 空剪辑项目，Then 出现素材准备入口，剪辑/海报默认收起，无可见预览画布；已有时间线及合成上游的审片、采用、剪辑、MP4 导出仍能完成。
- **AC-06** Given 有对应权限，Then 偏好设置顶部能进入模型、团队、后端配置；成员页不再出现另一套创建组织表单。无权限角色仍由原前后端校验限制。
- **AC-07** Given 手机模型绑定草稿，When 搜索、能力筛选或只看待配置后再返回，Then 草稿与展开状态保留；真实保存后状态更新且卡片不收起；仍执行版本和能力校验。
- **AC-08** Given 工作流，Then 桌面画布尽早出现，手机首个步骤可达且默认不渲染缩成缩略图的内嵌画布；展开画布后所有节点存在，关闭后选择和内容保留。
