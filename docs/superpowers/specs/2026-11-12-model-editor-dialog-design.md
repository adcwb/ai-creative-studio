# 模型管理编辑弹窗

用户已确认：模型和网关通过弹窗编辑，保留列表位置；保存成功关闭并更新列表，失败显示错误并保留草稿；表单内部滚动，底部操作固定；关闭未保存的草稿前确认。

## 方案

替换列表底部表单和自动滚动方案，复用原生 dialog 与现有 ConfirmDialog。新增入口也使用同一弹窗，以复用表单。背景不可交互，关闭恢复触发按钮焦点及页面位置，支持 Escape；保存期间禁止关闭和重复提交。

## 实施与验证

1. 共享弹窗外壳负责焦点、背景滚动锁定和关闭确认；继续复用现有表单及保存 API。
2. 表单内容独立滚动，固定标题和操作区；错误显示于弹窗内。保持现有 API Key 提交后清空策略，其他输入在失败后保留。
3. 更新桌面和手机浏览器用例：长列表位置、保存成功/失败、关闭确认、Escape、键盘焦点、内部滚动及中英文。
4. 运行类型检查、相关 ESLint 和模型管理浏览器回归。
