# 图像创作记录操作

用户要求并已确认：单条删除与清空全部已结束记录，不提供恢复；卡片直接继续编辑图片，每页四条、桌面 2×2，并展示实际像素分辨率。

## 最小方案

复用现有卡片、分页、确认弹窗和 ContinueImage 编辑入口。不另建历史页、回收站或图片编辑器。手机保持单列，卡片展示实际宽高，旧记录缺少尺寸时标为未知。

删除前确认，仅可处理成功或失败的记录，排队及执行中的任务保留。删除只永久移除用户可浏览的创作历史；执行实体、计费及幂等记录保留内部用途，不提供恢复或重新显示历史的操作。已保存素材及已复制到图片编辑工作区的文件不受影响。卡片继续编辑会将原图复制到现有编辑工作区，再进行修改、参考图生成或局部创作，不更改原图。

## 接口与一致性

- DELETE /api/v1/tasks/{id}/history：删除当前空间一条已结束历史，重复请求不重复变更，其他空间不可操作。
- DELETE /api/v1/tasks/history：清空当前空间所有已结束历史，返回删除数量，运行中任务保留。
- 删除状态复用任务持久化，文件和 PostgreSQL 存储行为一致。任务详情、原图和素材引用保持可用，历史列表与分页总数排除已删除记录。
- 分页默认每页四条；删除后重新加载并由后端修正超出范围的页码，过期读取不得让记录重现。

## 验证

覆盖删除权限、CSRF、跨空间隔离、重复删除、重启持久性、清空保留进行中任务、保存素材不受影响，以及桌面/手机的四条分页、分辨率、删除确认/取消、末页回退和继续编辑。
