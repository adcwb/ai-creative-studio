# 网关模型列表展示优化

根据用户截图优化现有列表，不改变模型配置、权限、绑定及同步协议。

采用紧凑工具栏和桌面表格：标题与添加/同步按钮分组对齐，网关筛选控制在约 300px，展示当前筛选的模型数量。模型显示名称与上游 ID 相同时不重复展示；不同时保留完整 ID。能力和功能引用分别换行显示，状态区分待配置、启用、停用。手机转换为保留字段标签的纵向条目，不要求横向滚动。保留键盘焦点、编辑入口、草稿及滚动位置。

```text
网关模型                         添加模型  同步模型
按网关筛选 [网关名称]              显示 N 个模型
模型 | AI 网关 | 模型能力 | 功能引用 | 状态 | 编辑
```

沿用现有森林绿 #193b2e、白色 #ffffff、画布 #f7f7f2、次要文字 #63705e、成功浅绿 #edf3e5、提示浅黄 #f6f2e7，以及既有中文无衬线字体；标题 18px、正文 13–14px、辅助信息 12px。所有内容左对齐，以列宽和文字层级组织信息，不添加动画、仪表卡、搜索或额外配置步骤。

相比将桌面列表全部改为卡片，保留表格更便于横向比较模型能力与绑定。仅手机采用纵向条目，解决窄屏可读性问题。

验证覆盖长名称、长模型 ID、多功能引用、筛选、同步、编辑保存和取消，以及桌面和手机截图与溢出检查。

实现后检查通过：ESLint、生产构建、86 项前端单元测试、10 项桌面与手机交互检查，以及国际化静态检查。使用长模型名称、完整上游 ID、7 个功能引用和三种状态检查 1920、1280、1024、390px 宽度，均无横向溢出。手机字段使用标签与值并排的紧凑排列。
