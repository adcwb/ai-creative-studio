# 映创工作台：可读性与主题一致性

## 方向

面向图像与短剧创作者，保留深绿导航、低干扰画布和三套现有主题。以作品和编辑任务为视觉中心，统一配置页的文字、控件和状态层级，不增加营销式大标题、装饰卡片或动画。

森林主题的六个基础色：导航森林绿 `#193b2e`、画布 `#f7f7f2`、面板白 `#ffffff`、正文墨绿 `#263e32`、链接绿 `#3f6149`、控件边界灰绿 `#7f8d78`。暖纸与深色主题分别保留原有底色，单独定义链接、控件边界、侧栏控件边界和焦点色。按钮背景仍使用 primary，避免为了提高链接对比度而破坏按钮上的白字。

中文正文采用已有苹方／微软雅黑系统字体栈，统一 14px 基线。辅助信息 11/12/13px，正文与强调 14/15/16px，区域标题 18/20/24px，页标题 28px。大幅登录画廊标题保留自适应尺寸。字号与间距即使数值相同也保持不同语义，不以消除相同像素值为设计目标。

```text
固定品牌与空间选择 | 页标题、任务说明
可滚动分组导航     | 左对齐表单 / 模型与资产列表
账户与设置入口     | 弹窗：标题 / 独立滚动内容 / 固定操作
```

保留已有布局比重新划分所有页面更适合本次修复。审视后移除了“所有组件强制使用同一组断点”和“700px 规则整体删除”的做法：业务组件有不同空间需求，素材与详情弹窗的移动规则仍有效。共享壳和其相邻内容使用 760px 边界，独立业务断点继续保留。

## 核实后的处理

- `tokens.css` 提供唯一基础字号，删除 app-shell 的字号和浅色背景覆盖，并移除主题内为其设置的 inherit 补丁。
- 共用界面中的常规字号改用语义令牌；7/8/10px 辅助文字提高至 11px。
- 所有原 primary/green-soft 前景色引用改为主题链接色；装饰和填充继续保留原色。深色主按钮 hover 也需通过白字对比度检查。
- 输入边框与表格分隔线分开。正文目标至少 4.5:1；控件边界和焦点目标至少 3:1。
- summary 和自定义可聚焦元素统一显示 focus-visible；深色侧栏使用浅色焦点。导航点击目标至少 44px。
- 只移除在源代码中确认无引用的旧单页导航、项目列表和文案区域，保留有效响应式规则。
- 保留 `.provider-real`：`ProviderBanner.tsx` 使用 `provider-${capability.mode}` 动态生成类名，纯字面量扫描会误判。

## 验证

使用真实浏览器的计算样式测量三套主题的链接、输入框、侧栏控件、普通/悬浮按钮和折叠标题焦点；检查登录页基线、移动导航尺寸和 640/700/760/761/900/1200px 布局。桌面和手机截图人工审阅；模型弹窗与导航测试回归；生产构建与 ESLint 检查。

审查依据：[Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md)。自动检查覆盖本次修改的样式与交互，不代表全站 WCAG 合规认证。

## 交付审查记录

- `frontend/src/tokens.css:7` — 已统一基础字号至 14px，共用界面的常规字号使用统一令牌。
- `frontend/src/layouts/themes.css:7` — 已分离三套主题的文字链接色和控件边界色。
- `frontend/src/style.css:11` — 已覆盖 summary 与其他可聚焦元素的键盘焦点。
- `frontend/src/layouts/app.css:15` — 已保证导航链接与分组按钮至少 44px，侧栏焦点使用浅色强调色。
- `frontend/src/style.css:224` — 已移除旧移动侧栏规则，保留素材、表单、详情弹窗的有效响应式样式。
- `frontend/src/style.css:54` — 已保留动态生成的 provider-real 状态样式，避免误删。

验证结果：生产构建下 9 项设计系统检查通过，1 项重复移动端断点检查按设计跳过；26 项模型管理与导航回归通过（其中 2 项旧编辑流程用例更新为弹窗交互后单独复测通过）。生产构建、相关 ESLint、diff whitespace 检查通过。已有主包超过 500 kB 的构建提示仍存在，本次未调整模块拆包。

浏览器实测的所选文字配对均达到 4.5:1，输入边界与焦点达到 3:1；这包含三套主题、按钮默认/悬浮、侧栏输入与折叠标题。登录页与工作台基线一致。已检查 640、700、760、761、900、1200px 视口无横向溢出。
