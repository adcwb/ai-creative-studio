# Ant Design 迁移后的 CI 与界面验收

日期：2026-11-14。基线：`c63c7d32383bca375f7d9d9a6b1edb4a4b733cb9`。提交时状态：本地修复与针对性验收完成；云验证以该提交的Checks为准，未把尚未运行的云检查写成通过。用户授权安全拉取、验证、修复后推送并跟踪云 CI，不部署生产、不制造空提交。现有独立工作树均保留。

## 目标与边界

US-ANT-CI-1：创作者使用迁移后的真实界面完成原有操作，组件库变化不丢失输入、权限、生成来源或结果恢复。CI 要以可操作的界面及当前合同验证功能，不把原生控件选择器误用到 Ant Design，也不删除失败断言或缩减必需覆盖。

US-ANT-CI-2：保留现有三主题、C 端桌面/手机风格。图像候选应该完整可见，不能因基础按钮默认高度把预览挤成横条。测试中的模拟供应商仅是隔离验收设施，不能成为产品失败时的回退。

不修改生产模型配置、凭据、项目额度、认证或租户隔离；不部署、不调用付费模型。本轮修改 UI 兼容样式、验收脚本与测试合同，不恢复已明确简化的候选必经流程。
