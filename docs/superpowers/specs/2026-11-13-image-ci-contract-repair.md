## 证据与根因

1. 路由测试服务对带 `page/page_size` 的 `/tasks` 仍返回数组。实际后端此时返回 `items/total/page/page_size/running`；未带分页参数才保留旧数组。未修改版本的本地 Playwright trace 记录了分页请求、数组响应和 `TaskList` 读取 `undefined.length` 的 React 异常。应修复 fixture 契约，不能删除页面就绪/导航断言。
2. 图像记录的保存/重试操作按新设计移至详情；`studio`、`i18n`、`iteration` 和 `provider_check` 仍点击卡片上已不存在的按钮。本地未修改版本实际完成生成并显示图片，随后等待旧保存按钮超时。修复为通过“查看详情”操作，继续核对保存、语言切换后状态、刷新持久化、取消草稿、键盘焦点、重试原键与唯一子任务。
3. 新卡片只保留“模拟完成”，丢失了先前明确的“模拟图像 · 非 AI 生成”来源提示。网关模式下历史模拟图像仍需诚实标识；使用既有来源函数和样式恢复紧凑标签，保留 consumer 验收原断言，不靠测试提示词本身表达警告。
4. CI 的供应商集成失败后未运行的布局脚本也仍使用旧重试入口，并把设计规定的两行摘要视为文本丢失。改为经过详情重试；对收起的摘要同时验证两行样式、详情完整文本、可读尺寸与水平无溢出，不取消长文本验收。

## 可测试验收标准

- AC1：Given 已有跨空间任务，When 查询新旧列表接口，Then 路由 fixture 和实际后端均支持分页包络、倒序、总数/运行数与末页修正；无分页查询继续返回旧数组。
- AC2：Given 八条个人记录与独立团队记录，When 在桌面或移动端翻页、导航、切换空间，Then 分页显示 6+2 条，前后页边界正确，路由往返保留页码，切换空间回第一页且记录不混入其他空间；无页面异常。
- AC3：Given 成功和失败图片，When 按真实 UI 从详情保存或重试，Then 成功图片从详情保存，刷新后素材仍存在；中英文切换后已保存状态正确；失败任务从详情编辑，取消恢复原草稿，不创建额外任务；响应丢失后保持同一幂等键，仅创建一次重试任务。
- AC4：Given 网关空间中有历史模拟任务，When 显示画廊，Then 网关界面中历史模拟卡片仍有系统生成的“非 AI 生成”提示，真实图片保留其真实来源，用户配置能力不被修改。
- AC5：Given 空、完成、长文本和重试记录，When 在各视口浏览，Then 1280/1440/1920 桌面、短屏、1040 堆叠与 390 手机布局覆盖空、完成、长文本和重试态；两行摘要对应的完整文本可在详情读取。
- AC6：Given 本地合成 HTTP 上游，When 执行并重启真实应用，Then 验证真实应用执行、原图字节、保存/重启、错误脱敏、中断和显式重试，无自动重复上游调用。合成验证不代表真实模型权限或生成质量。
