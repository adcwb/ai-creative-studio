状态：本轮基础闭环已完成；第 6–10 项整个创作路线仍有未覆盖内容，不能称为全部完善。真实模型效果和商业能力仍以验收边界为准。基线：a89272379d5ca29e11bef3f1144d8addb05ebf2c。保持现有 C 端设计系统、人工决定、真实模型执行链，不增加项目额度或成本门槛。用户授权本阶段完成并验证后推送及跟踪 CI，不部署生产；下一阶段画布及数字人先本地实施，不提前混入本次提交。

## 用户故事与交付边界

- US1：创作者只想恢复某镜头、配音或字幕时，可预览旧修订与当前剪辑的差异，再明确恢复所选部分。保留当前其他内容、旧成片和全部历史，不恢复权限/模型执行/发布状态。
- US2：美术与导演复用固定版本资产，能看到参考资产已更新及本次是否需要复查；不会自动替换旧镜头。以项目绑定核对为首个闭环，不宣称概率性参考图等于锁脸。
- US3：编剧/导演在一季内逐集检查剧本、分镜、镜头采用、未处理审片和成片，直接进入对应工作区；沿用现有季集节拍与真实连续性检查。不是跨集自动批产。
- US4：创作者为一个已成功导出的正式成片下载包含视频、字幕和字节校验清单的 ZIP 交付包，清楚知道尚未对外发布。预演不能伪装成正式交付。
- US5：个人/团队空间明确显示能力与权限，团队可改名、普通成员可主动退出，所有者不能丢弃唯一所有者身份。操作均需当前权限、CSRF、版本和明确确认。此阶段不接支付、商业订阅、项目额度，也不把邮箱当作已验证身份。

局部恢复首期对象为已保存的剪辑：整个时间轴或固定 clip ID 对应的镜头/音频/字幕。剧本和分镜内容仍使用已有候选、版本与人工采纳流程，不进行多仓库全状态回滚。连续性以正式故事资料、版本提示、现有 AI 检查和人工处理为准；不承诺真实角色/声音的艺术效果。高级跨集消费图/自动重做、200 集编排继续延期。

## 需求与实现

FR1 MUST：只读预览与显式恢复分离；源修订属于同空间/项目，提交固定 revision/component/clip、媒体版本及原请求键。幂等重放不覆盖后续编辑；权限撤销仍拒绝。格式、现存素材与 ASR 来源不合法时原子失败。
FR2 MUST：参考版本检查只读取当前用户有权读取的绑定；报告固定版本与最新版本、归档/不可用情况，不读其他空间内容，不自动升级或生成。
FR3 MUST：季集概览使用现有分页目录，只返回当前页紧凑状态；读取不触发生成、不改变状态，不以“released”手工标签冒充平台发布成功。
FR4 MUST：交付只允许正式成功导出；内容使用该导出固定时间轴与集号。视频/字幕流式写 ZIP，固定安全文件名，manifest 包含 SHA256，不包含凭据、内部路径或原始上游响应。权限沿用项目下载边界。
FR5 MUST：个人空间保持仅本人，团队改名/退出不能移动作品、破坏唯一所有者或放宽角色；CAS 冲突保留输入。版本区分属于产品能力，不添加许可证/配额。

实现计划与验收见 [tasks.md](tasks.md)。既有存储字段保持兼容；预计复用媒体回执、修订、空间版本与既有关系表，不在线创建生产 DDL。若新增结构，必须先补迁移/备份及旧数据测试。
