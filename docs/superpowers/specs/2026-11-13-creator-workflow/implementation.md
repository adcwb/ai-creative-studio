# 实现与兼容说明

代码基线：`a89272379d5ca29e11bef3f1144d8addb05ebf2c`。本轮对应任务清单第 6–10 项的可验收改进，沿用已有真实生成、编剧及连续性工作区；不把长期规划中的所有功能标为完成。

## 操作与接口

| 用户操作 | 接口与实现 |
| --- | --- |
| 剪辑页保存制作修订，查看来源，选择集/镜头/字幕/声音/完整剪辑，预览前后并明确确认 | GET `projects/{id}/revisions/{revision_id}/restore-plan`、POST `restore-timeline`；`revision_restore.go`、`RevisionRestore.tsx`。项目与媒体 CAS，既有媒体回执；原请求恢复不会重复覆盖后续修改。 |
| 角色与美术页核对固定参考版本 | GET `projects/{id}/library-bindings/check`；`library_binding_check.go`、`ProjectReferences.tsx`。返回当前/有新版本/归档/不可用，附检查时的媒体版本；只读。授权仍由既有派发链检查。 |
| 系列页逐集查看制作事实并进入对应工作区 | GET `seasons/{id}/episodes?include_production=true`；`series_production.go`、`SeriesPage.tsx`。沿用游标分页，显示脚本/分镜及过时提示、已采用镜头、未解决审片、正式成片；手工状态明确标记。 |
| 正式成片下载发布交付包 | GET `projects/{id}/media/exports/{export_id}/delivery.zip`；`media_delivery.go`、`MediaStudio.tsx`。流式 ZIP，MP4/SRT/VTT/固定时间轴与集身份/SHA256清单/边界说明。 |
| 团队页改名、非所有者主动退出 | PATCH `organizations/{id}/settings`、POST `organizations/{id}/leave`；`auth_space_settings.go`、`TeamSpaceActions.tsx`。CSRF、审计、当前 RBAC、空间版本和显式确认；退出不删作品。 |

完整请求响应和失败状态以 `api/openapi.json` 为准。剪辑素材预览只展示源文件，不假装已渲染转场、裁切或混音；确认后需要重新合成。旧项目的多集剪辑逐集恢复，系列项目继续一集一项目。未保存剪辑、上传或待核对操作会阻止从旁边恢复；恢复期间冻结剪辑表单。丢失响应后重载会重新打开原修订的恢复入口，保留同一请求键及请求体。

## 数据与权限

本轮没有新增数据库表、生产 DDL、全状态迁移或生产写入。剪辑恢复使用现有 `MediaState` 和媒体回执；个人/团队管理使用既有组织版本和受约束的 RBAC 关系。恢复不会写回旧脚本、旧授权、模型任务、成员、素材采用决定或平台发布记录。所有跨项目/空间访问按现有边界拒绝；恢复提交和原请求重放都重新检查当前写权限。

团队改名和成员退出不改变组织 ID，因此作品、模型及旧记录不移动。旧客户端仍可读取原数据；新 GET 字段 `production` 为可选，只有显式请求才附加。退出在同一持久事务中移除成员并增加组织版本，其他 API/worker 按既有数据库授权读取即时失权。丢失响应后的团队操作必须重新读取状态再确认，不能把重试当成未执行。个人空间不共享，所有者不能退出；所有权转移、删除团队及商业订阅未在此轮开放。

备份/回退仍须停掉所有 writer，数据库与 DATA_DIR（含私有密钥、素材、回执）保持匹配；不因无新 DDL 而省略部署维护措施。本轮不部署、不执行生产迁移。

## 验收边界

- 已有镜头、配音、字幕生成/候选采用及局部调整继续走真实网关链；新增恢复和核对本身不调用模型、不产生模型费用。
- 资产固定与版本差异是可追溯性，不承诺真实模型角色一致性、克隆声音或商业许可。当前资产类型沿用人物/产品/场景/风格/声音；道具可用产品或场景卡表达，未新增专用道具模型。
- 已成功正式导出不意味着与最新剪辑相同、已获法律许可或已经对外发布。交付 ZIP 固定所选成片和当时的时间轴，后续编辑不会更改它；不向外部平台提交。
- 系列创作圣经、季集节拍、真实文本连续性检查和人工采纳复用既有实现。本轮补充逐集观察与进入工作区，不新增跨集自动生产或影响依赖图。
- 个人/团队协作基础可用，商业套餐、支付、计费、项目额度和邮箱验证邀请不属于此轮实现。
- 真实供应商、商业授权、真实 5–10 集角色连续样片、原生 4K 画质和真实平台发布仍未验收。合成供应商与 FFmpeg 测试不冒充这些结论。

下一阶段的拖拽画布和数字人另立规格与验收；此轮通过并推送后继续，先保留本地，不混入本次交付。
