# 前端路由与布局重构

用户已确认采用应用外壳、独立路由页面与项目内分步工作台方案，并授权实施。

## 页面与导航

- `/studio`：图像创作，参数与结果双栏。
- `/assets`：图像素材库，与创作页共享当前空间的图像工作区状态。
- `/projects`：短剧项目列表。
- `/projects/new/brief`：创建项目。
- `/projects/:projectId/:section`：brief、script、storyboard、media、publish 五个项目工作步骤。
- `/settings/organization`、`/settings/models`、`/settings/billing`：独立管理页面，沿用现有组织权限。
- `/social-callback`：保留授权回调。
- `/` 重定向到 `/studio`，未知路径展示找不到页面。

## 实现边界

路由与空间上下文位于 app；应用外壳位于 layouts；路由入口位于 pages；图像、项目编辑状态位于 features；复用业务控件继续使用 components。不为目录重组迁移无关文件。

组织切换重建工作区，避免串用数据。空间选择在当前浏览器标签页中保存，并在服务端返回可访问空间后校验。管理页面按实际角色展示，直接访问无权限路由也显示明确状态。导航离开时保护未保存的项目草稿、处理中或结果不明请求；硬刷新使用 beforeunload。

## 视觉约定

保留森林绿 #193b2e 与品牌素材，白色 #ffffff 为工作面，浅灰 #f4f6f5 为画布，正文 #263e32、次级文字 #63705e。使用现有中文系统字体，正文提升到 14px，页面标题 26–30px。侧栏宽 240px，工作区随窗口扩展，普通表单限制阅读宽度。空间选择置于导航顶部，语言与账户置于底部。移动端使用抽屉导航。去除占据工作区的宣传块，以页面名称和操作说明取代。

## 实施顺序与验收

1. 安装路由依赖，落地会话、空间上下文、导航拦截与应用布局。
2. 提取图像工作区状态，建立创作、素材与管理路由。
3. 拆出项目列表及五个工作步骤，保持原有生成、保存、版本冲突与发布交互。
4. 调整响应式样式与中英文文案。
5. 运行类型检查、lint、单元测试和生产构建；验证直接访问、刷新、前进后退、角色限制、组织切换、草稿保护及桌面和手机布局。

现有端到端测试中的工作台按钮和折叠管理面板入口需改为路由链接；项目媒体、分镜与发布用例需先进入相应步骤。

## 实施与验证结果

已完成路由拆分、侧栏与手机抽屉、表单布局、按路由加载、项目步骤组件拆分和统一导航保护。图像状态保持在当前组织的应用生命周期内，以保留跨页面草稿和结果未知请求的幂等键。项目步骤切换在用户确认放弃后清除本地编辑状态，结果未知的请求保留核对入口。管理表单和发布工具也纳入离开保护。

验证通过：TypeScript、ESLint、40 个单元测试、生产构建，以及 14 个使用本地合成 HTTP 服务的桌面与手机浏览器用例。另已复查 1440/1920 宽屏与手机截图。原有后端端到端用例已迁移导航入口并通过用例收集检查，但未执行真实后端集成：本机 Windows 构建后端时遇到 `syscall.O_NOFOLLOW` 和 sonic 的 `GoMapIterator` 编译错误。详细运行方式见 `frontend/README.md`。
