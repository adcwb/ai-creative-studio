# T41B：独立静帧预演

日期：2026-11-06。实现起点：`eac46d5ebfc6315851e4a690980a03c7eeb49c8c`（T41A）。本阶段补齐T41的静帧预演退出条件，规格整体仍为Implementing。T42–T45、剩余P0A及T51–T53尚未完成，全部实施与验证前不推送、不部署。

## 创作者如何使用

在现有“分镜与预演”中展开“静帧预演 · 先看节奏”，选择本集已保存镜头及真实项目图片，调整顺序、时长与画幅。可用本集已采用图片起排，也可逐镜选片、重复同一镜头。不会把缺图镜头换成占位图。独立无归属镜头由创作者明确指定本次集归属，不修改原镜头；脚本镜头按分镜原始剧本版本判定，不能拿后来改序的剧本猜测集数。

声音明确选择静音或本项目临时声轨；临时声轨从头播放，超过该镜长度截断，不足部分静音。剧本对白和导演声音意图保留在来源记录，不自动变成声音或字幕。该操作只进行本地FFmpeg合成，不需要模型、报价或额度配置，不发起任何上游生成。真正制作图片、视频和声音仍使用已实现的真实网关链，不增加模拟模式。

产物为独立360p节奏预演，画面实际烧录`ANIMATIC - SILENT PREVIEW`或`ANIMATIC - TEMP AUDIO`。正式成片的1K–4K选择独立保留；本阶段没有给静帧附加镜头运动或把预演宣传为原生视频/4K。历史默认仅读分页元数据，展开时才读取固定镜头和声音来源。可播放、下载带animatic文件名的预演、取消和按原检查点恢复。

沿用现有面板、绿色主按钮、表单与手机纵向布局，无新主题或依赖。空状态、缺图、角色只读、加载、来源变化和不确定写入有明确提示。重新核对保留创作者已选画面、排序和时长，要求核对过期项，不自动清空选择或修改正式素材采用。展开内容较多时纵向滚动，不将完整来源放入轮询正文。

## 数据与一致性合同

- `modules/media/animatic.go`定义纯数据快照；现有`MediaExport`新增可选`purpose: animatic`和`preview_source`。来源固定项目/剧本/分镜来源/媒体版本、本镜完整导演意图、原序号、实际播放次序、图片/音频ID、名称、字节SHA和大小。不保存私有文件路径、运行时密钥或虚构授权。
- `application/media_preview.go`按core→media锁顺序接纳，项目与媒体双CAS，已接受原回执优先于版本检查。相同key/body返回同一预演，后来剧本/正式剪辑变化不会替换原输入；同key异body拒绝。接纳仅写export、receipt和queue，不更新项目、timeline或selections。
- PG沿用现有媒体事务、队列、租约/fence，export/receipt/queue原子提交；文件模式沿用现有有界本地队列。工作槽不足排队，没有新增项目预演次数、数量、累计时长或成本配额。
- 接纳时固定真实字节；执行前即使没有检查点也复核SHA/大小。`render_checkpoint.go`将purpose和来源摘要纳入预演manifest，沿用分段视频、PCM、合并校验及进程崩溃续跑。源字节变化明确拒绝，不改用当前图片。纯typed来源摘要支持PG JSONB键序变化；返回快照深复制，不允许调用者修改已存来源。
- 原正式成片没有purpose/source时保持原manifest字段省略及旧摘要行为；旧成片可读。取消、恢复和检查点保留同一预演身份，不能转成新正式剪辑。
- UI区分正式导出与预演；社交候选过滤所有非空purpose，服务端`socialSource`拒绝预演用于正式发送，不能靠直接HTTP绕过。当前读权限仍控制详情和文件下载。

## HTTP和恢复

| 方法与项目内路径 | 合同 |
| --- | --- |
| GET `media/previews/options` | 分镜投影、精确历史集归属、项目/媒体版本、素材/采用信息；不返回整份剧本/历史或导出正文 |
| POST `media/previews` | 双版本、集号、画幅、声音模式与镜头/真实素材/时长；202返回独立预演，严格拒绝客户端伪造来源 |
| GET `media/previews?limit=20&cursor=…` | 分页元数据；1–100为单页大小，非历史总量限制；游标校验空间/项目 |
| GET `media/previews/{id}` | 当前读权下按需读取固定来源 |
| POST `media/previews/{id}/cancel`、`resume` | 当前写权、CSRF与原key/body恢复，目标必须为预演 |
| GET `media/exports/{id}/file?download=1` | 保留现有读权，预演返回带标识附件名；无flag正常内联播放 |

OpenAPI、前端调用和实际安全HTTP脚本同步。页面复用`useSeriesWrite`保存原body/key、跨刷新恢复和离开保护。仅预演的replay-first路径可将明确`409 version_conflict`视为“原请求未接纳”的证明，清除不确定状态并保留选片以便重新核对。通用写入默认语义保持不变；403等权限失败不能消除曾经接纳的不确定性，不能换key盲发。

## 兼容与升级

没有新表、DDL或依赖；新来源随既有媒体JSON与备份离线往返。旧正式记录缺省可选字段，行为保持。上线仍需匹配API、worker、前端版本并停旧writer，不能让旧程序写回丢弃新JSON；本轮未执行生产迁移或部署。预演不授予素材模型派发/克隆或社交发布许可，实际模型消费仍受已有当前授权保护。

每镜最短0.5秒沿用现有时间轴格式，有限数字及帧/采样整数溢出属于实际数值边界；未增加总镜头或总时长限额。已存在的上传媒体180秒限制、全局core/media scope读写、长期存储热点、公平资源调度由剩余P0A/T51–T53处理，本阶段不声称已移除这些限制或完成200集生产能力。
