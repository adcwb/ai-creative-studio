# 系列工作区、集号与导出关联实施记录

日期：2026-11-05。状态：**T31元数据工作区闭环已实现；T32及后续连续性、导演编排和完整生产容量未完成**。本批开发基线为本地 `ce979c04f2bdcbebfb6982cf94cbf1baef97a509`，接续[存储基础阶段](series-storage-implementation.md)。按用户授权只做阶段本地提交，完整Spec完成并验证后才推送，不部署或调用收费模型。

## 用户操作与创作边界

1. 在“短剧创作”选择“系列漫剧”，新建系列，记录故事方向、目标观众和表现形式。默认90秒/集、1K·1080p、9:16；可选择1K–4K及横/竖/方画幅，同时显示准确输出像素。建议1–2分钟，不把120秒变成拒绝更长目标的额度。
2. 添加一季，再添加剧集。每集进入独立项目，复用既有简报、真实网关剧本/分镜、角色美术、镜头制作、剪辑与发布入口。保存目录不调用模型；文字模型不会被当作图片或视频模型。
3. “调整集号/季号”可选择交换编号，或插入目标位置并顺移中间内容。例如先新增第201集，再把它插到第7集，原第7集变第8集，作品ID、项目ID和已有成片身份不变。并发变更通过父级及当前实体版本拒绝过期修改。
4. 目录展示项目当前标题和简述，修改在该集“项目总览”完成。当前稿/媒体内部只使用本地集号1，界面显示外部季集号；旧独立项目继续保留其多集编辑入口。
5. 未确认的保存保留原请求与幂等键，可刷新后再次打开相同表单核对。暂时失权并不能证明原请求从未保存，因此不会因一次403丢掉待核对记录；恢复权限后仍使用原请求。普通草稿有既有离开确认。恢复记录按当前用户、空间及操作隔离；浏览器拒绝会话存储时保留本页内存记录并提示离开前确认，不能承诺此时跨刷新恢复。

这仍是逐集创作工作区，没有自动写完整季/200集、自动保证人物一致、正式世界观账本或制作DAG。艺术取舍和启动模型由创作者明确决定。

## 实际代码与合同

| 范围 | 文件与行为 |
| --- | --- |
| 目录HTTP | `backend/internal/application/series_http.go` 注册 `/series`、`/series/{id}/seasons`、`/seasons/{id}/episodes`、`/episodes/{id}` 及季/集设置和编号调整。默认20/最大100是单次传输页大小，不是总集数额度。响应只含目录元数据与当前项目标题/简述/版本，不返回整季剧本或素材 |
| 一致目录版本 | `seriesrepo/context.go` 在文件锁或PG重复读事务内读取系列/季/集，父实体缺失报存储错误，不能误当独立项目。季集游标绑定空间、父实体、过滤条件及父版本；创建、编号和元数据变更推进父版本，继续过期游标返回409，用户重读后翻页，避免重排时漏集 |
| 插入及原回执 | `seriesrepo/store.go` 同一事务交换或顺移编号；`Command.mode` 是可选且空值不入摘要，保留此前已接受命令的原摘要合同。节点、父时钟和回执一起公布，编号变动不改项目内容 |
| C端页面 | `ProjectsPage` 增加既有风格的两类目录，`SeriesPage` 及 `features/series` 提供空状态、错误重读、分页、表单、版本冲突、归档和恢复。系列视图不额外请求旧整体项目列表。沿用现有背景/深绿/白面板、按钮、导航、设计tokens、离开确认及响应式布局，无新视觉体系 |
| 单集边界 | `ProjectEditor` 使用系列上下文；`DramaScriptEditor` 显示真实集号并隐藏内部集号输入，`MediaStudio` 不显示“打开其他集”。后端拒绝向系列项目保存其他本地集号的剧本、时间线或导出，旧项目语义不变。仍需通过既有认证、组织权限、CSRF、能力和审核 |
| 真实生成 | `project_store.go` 保存生成时的 `source_episode_id` 和 `target_duration_seconds`，文件与PG worker均传入同一输入。`project_instructions.go` 向实际text请求提供单集/目标时长，拒绝上游返回多集内容覆盖当前稿。去掉文字提示中固定“两人物三场景”和分镜只引用前三场的假定，按实际故事/场景规划；未增加模拟回退 |
| 输出与可恢复错误 | `series_media.go` 仅为尚未保存媒体的项目应用默认输出档；持久时间线和后来手工选择不随目录默认值改变。已校验的读取返回存储错误，不静默返回360p；临时目录故障不永久封锁媒体。写入返回与持久化一致的默认值，并与PG/文件缓存脱离 |
| 成片来源 | `MediaExport.series_episode` 固定系列/季/集ID、导出时季集号和内部集号1，实际输出档来自该次不可变时间线。以后重排不改旧成片；媒体页和发布素材选择使用导出时编号，而不是新的目录编号 |
| API与语言 | `api/openapi.json` 同步新增请求/响应、只读来源和导出快照；中英文本、TypeScript及HTTP合同覆盖同步。新增接口不能通过正文伪造当前用户或项目关联 |
