# 实施记录：自定义纯文本图像提示词

日期：2026-11-05。开发基线：本地`c6de2a6befcd4680623f7262a138081fa850a030`。状态：P1纯文本闭环已实现；完整Spec仍在实施。用户最新授权为全部规格完成并验证后推送GitHub、核验CI；本阶段仅本地提交，不提前推送，不部署、不执行生产迁移、不调用收费模型。

## 已实现的创作流程

图像页保留既有内置灵感，新增“我的提示词 / 组织共享”。创作者可从当前描述或成功任务打开可编辑草稿，填写名称、简述、分类、标签、默认类型/画幅/风格和版本说明。默认私人，明确选择后可分享至当前组织。保存不调用模型。选用只预填；已有正文会先确认替换，可取消以保留原稿；真正生成继续使用现有功能绑定、模型选择、审核及网关任务执行链。

支持编辑、搜索正文与名称、精确分类/标签过滤、本人收藏、分页、归档/恢复、复制、新版追加和历史查看。可以用历史正文继续编辑并保存为新版本，原版本不会被覆盖。共享界面明确说明所有历史版本可被组织成员读取；将私有历史共享须额外确认。正文与用户名称按原文呈现，不经过翻译函数或HTML执行。

保存响应不确定时冻结原请求并保留路径、正文与幂等键；恢复记录按当前用户和空间隔离于会话存储。刷新后可明确恢复原保存，不会悄悄重新建版本。CAS冲突保留草稿，允许另存新身份；确定的拒绝不会当作已保存。

## 实现边界

- [prompts业务模块](../../../../backend/internal/modules/prompts/prompts.go)：纯文本配方、可见性、字段/Unicode校验、不可变版本与来源值；不依赖HTTP、SQL或模型供应商。
- [promptrepo仓库](../../../../backend/internal/persistence/promptrepo/store.go)：PostgreSQL独立实体表，版本和回执同事务提交，按组织和当前用户过滤。文件模式以每模板追加的原子事务文件存储元数据、版本及回执，不新增全站scope或累计条数门槛。历史分页不把所有正文装入应用scope。
- [HTTP](../../../../backend/internal/application/prompt_http.go)：创建、列表、单项、历史、追加版本、元数据、复制、收藏与纯预览。版本追加可同时更新元数据，必须同时满足head和row版本，避免表单保存一半。
- [来源固定](../../../../backend/internal/application/prompt_source.go)：任务保存template/version、编译及最终文本摘要和edited。新请求重新检查所选版本可见性/归档状态；已接受同键重放和原失败任务的精确重试使用已保存任务输入，不跟随新head。来源模板改回私有不能撤回已合法生成的组织任务文本。
- 管理员没有私人正文读取旁路。额外提供`POST /prompt-templates/{id}/admin-archive`用于当前组织owner/admin的审计归档，要求预期row版本；响应只含ID、状态、row版本。此管理接口不授予读取历史或改写私人正文的权限。
- [前端](../../../../frontend/src/features/prompts/PromptLibrary.tsx)：复用现有卡片、原生dialog、字体、深绿/浅底/白面板和设计tokens；桌面卡片网格、手机单列，不重做导航或引入另一套视觉体系。

纯文本中的`{{name}}`按字面保存，不解释为变量。本阶段没有实现变量编译、参考配方、系列/季/集、连续性账本、导演工作台、制作DAG、渲染检查点及200集容量证明；后续按计划推进，不能因P1闭环成功宣称这些完成。P0A遗留的文件库64MiB快照、整体scope热点与其他基础依赖仍在[第一批记录](implementation.md)中跟踪。

## 迁移与运维

新增`studio_prompt_templates / studio_prompt_versions / studio_prompt_receipts / studio_prompt_favorites`，启动readiness要求这些列存在。现有PG部署需先备份、停止API/worker，再用相同版本离线迁移器`store-migrate --mode init --confirm-stopped`创建增量表、核对运行角色DML权限，再启动。API不会在线代替迁移账号执行DDL。

文件模式自动建立独立`prompts/`目录；离线file↔PG迁移已注册，原生PG备份包含新增表。不要只复制旧state.json而遗漏提示词目录。旧程序不认识新表/目录和来源字段，回退应先停止写入并使用同版本备份或前向修复，不承诺降级写入后保留新增数据。
