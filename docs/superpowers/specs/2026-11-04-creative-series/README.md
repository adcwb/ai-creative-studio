## 目标设计选择

- 提示词是一份可版本化的创作配方，包含意图、文本、少量变量、参考资产和适用说明；使用前允许修改，保存与使用都不自动调用模型。
- 长篇以系列—季—集组织，**新系列每集关联一个独立项目**，复用现有剧本、分镜、素材、剪辑与导出。旧多集项目保留兼容视图，通过显式迁移拆分，不能自动重编号或丢素材。
- 世界观、角色弧线、关系与伏笔是正式创作资料；AI 可给出候选和检查建议，正式采纳由创作者完成。
- 先定剧本与动态分镜，再逐镜生成、比较、选片和审片；人工确认发生在艺术选择处，批量任务不逐项询价。
- 配置好并启用、能力匹配的模型直接使用；项目不自设预算、小时次数、素材/导出/剧集/历史条数和累计存储配额。资源不足排队，保留组织权限、实际能力、独立审核、幂等和实际基础设施健康保护。
- 1K–4K成片均支持完整60–120秒，不沿用“1080p最多60秒、4K最多15秒”的旧耦合；以按镜/分段渲染、流式存储与续跑保护资源。源素材尺寸、升采样方式和实测输出像素明确展示。
- 支撑 200 集需要去除整体快照读写瓶颈并补充生命周期管理；仅提高数字上限不算完成。

本包在“自定义提示词、系列长篇、执行计划中的费用语义”范围替代 2026-10-28 总体提案的对应未来设计。旧实现和历史验证不被改写。存在独立审核、供应商能力及资源限制的现状在需求与验收中明确保留。
