# 创作工作区实施说明

用户已确认目录与竞品评估后的分期方案，并于 2026-10-29 授权实施。

## 本次实施顺序

1. 导航按图像、短剧、数字人、资源、发布和设置组织。创作容器增加 kind，旧项目视为 drama；图像和数字人作品不再混入短剧列表。旧链接保留可访问。
2. 图像工作区复用受控素材、遮罩和生成任务，支持导入原图、继续编辑、对比、选用及版本来源。模型不可用时仍可上传、比较和整理本地素材；实际生成与局部重绘依赖可用适配器。
3. 剧本支持可编辑角色、对白归属、场次增删和分集字段；分镜引用按真实来源剧本校验。允许无剧本手工建立镜头。
4. 镜头制作集中展示镜头、参考、候选、采用记录与返修批注。选择结果不自动覆盖剪辑；替换片段时保留时间、字幕、独立声音并验证素材时长。
5. 剪辑预览同步视频原音、配音、音乐和独立音轨；保持现有导出限制可见。
6. 发布中心选择具体作品，复用现有发布能力；交互型、3D 数字人显示准确的能力边界，禁止伪造可运行引擎。

## 合同与兼容

- 复用 api/openapi.json。project.kind 是可选枚举 drama/image/digital-human，缺省 drama。项目修改不改变类型。
- Script 支持 0–30 角色、1–120 场；每场 0–100 条对白，episode_number 缺省 1。没有对白的场景合法。
- Storyboard 支持 1–120 镜，scene_index=0 表示独立镜头；非零引用必须存在于来源剧本。变更剧本保留已有分镜并标记过期。
- 媒体状态追加采用与审片记录；写入使用版本比较和幂等回执，保留空间隔离，不隐式调用收费模型。旧状态无需丢弃或重建。
- 当前适配器不支持的多参考、动作参考、首尾帧等组合不能假装已执行；新增供应商接入需独立核对当前供应商合同和真实样片。

## 视觉与交互

沿用映创深绿 #183d30、纸白 #ffffff、工作区灰 #f4f6f5、正文 #223b32、辅助灰 #64746c。沿用现有中文无衬线字体。主内容左对齐；画面与镜头是工作区中心，设置在侧栏，工具栏直接作用于选中对象。导航不用步骤编号；桌面并列比较，移动端纵向展示。保留键盘、焦点、未保存保护和中英文。

## 验证

验证新旧项目兼容、角色与场次编辑、独立镜头、非法场景引用、媒体版本冲突、幂等、跨空间隔离、候选选择不修改时间轴、返修不覆盖原图、音频时间计算、导航及桌面/移动工作流。真实模型质量、商业账号权限及生产发布不由本地模拟测试代替。

## 本次交付状态

- 图像、数字人作品有独立持久化容器和路由；发布中心可选择所有类型的作品，旧短剧链接保持可访问。
- 图像可从生成结果继续编辑，支持原图导入、参考图、遮罩、候选比较、采用记录与来源追溯。上传响应以 uploaded_asset_id 指向本次请求的准确素材，重放不误选后续上传。
- 剧本解除原先两角色三场的固定结构，支持手写、无对白场次、集数、角色与对白调整；分镜可从独立镜头开始，增加叙事、表演与连续性说明。
- 镜头制作保留既有配音、音乐、音效、口型同步、图像分析及跨镜头外观检查入口；各能力仍由真实配置决定，合成演示明确标注。
- 采用与返修批注按媒体版本并发控制，持久化且有幂等回执；采用不改动剪辑。可显式将采用素材加入时间轴。
- 替换画面保持片段时长、字幕、配音和原视频声音来源；剪辑预览增加声音同步。
- 新建作品、JSON 制作操作、原图导入保存会话内请求标识，支持刷新后核对。原始二进制上传在本次页面挂载内保留重试请求；刷新会结束未确认上传的本地恢复，但已入库素材仍在作品中。

## 验证结果与范围

- 生产构建、TypeScript、ESLint、中英文静态覆盖、44 项前端单元测试通过。
- 30 项桌面与手机浏览器路由测试通过，包含新作品分离、数字人入口、采用/批注、刷新重放、旧链接与未保存保护；截图已检查。
- projects/media 领域测试通过；Linux 下项目、分镜、生产决策、上传回执相关 HTTP 与存储回归通过，含重启恢复、版本冲突和跨空间访问。
- OpenAPI 结构校验通过。实时 HTTP 合同全量检查和完整媒体导出回归未完成：本机 Docker 引擎中断，WSL 随后只读挂载，缺少可用 FFmpeg。应在具备媒体依赖的 Linux CI 继续执行现有合同与端到端检查。

## 后续能力边界

以下为第一批交付时的范围快照；多参考、帧控制、分集时间轴及审片分工的后续实现见 [第二批交付说明](2026-10-29-production-phase-two.md)。

交互型与 3D 数字人目前是独立入口及准确的不可用状态，尚无可运行引擎。多参考图、首尾帧、动作参考、自动身份一致性、多集独立时间轴与多人审片分工尚未新增；场次集数与文字连续性说明不等同于这些能力。既有时间轴仍限制每作品 30 片段、媒体 120 份，各清晰度导出时长维持现有限制。真实生成质量、真实语音表现及平台发布权限需使用配置好的服务另行验证。
