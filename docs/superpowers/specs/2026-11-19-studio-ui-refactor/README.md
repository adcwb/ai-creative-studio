## 需求方已定调（2026-11-19）

视觉方向取**深绿深色化**，延续既有「映创」品牌与映窗标记，不另起炉灶。主题收敛为**一套深色 + 一套亮色**，现有 forest / paper / screening 三套中的后两套下线。组件库边界取**一次性全面 antd 化**作为终态。首批重点页面为**项目列表、创作工作台首页、登录**。

2026-11-19 追加确认「开始改造」，第 9 章六项开放项按方案默认值执行：旧偏好 forest/paper → 亮色、screening → 暗色、新账号默认暗色；画布/时间轴/遮罩/3D/原图查看器继续自持；剧本页排在 S6；流式落差接受阶段式反馈；新增 react-virtuoso 一个依赖（S5 实测后定稿）；任意两版自由 diff 与单场 AI 重写本轮不实现。
