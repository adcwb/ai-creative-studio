## 创作体验与验收边界

创作者维护同一组人物、场景、道具、画风和声音；在系列内准备集纲候选，审阅后才成为正式计划。资产更新时先看影响到哪些集、哪些固定版本；不自动替换既有作品或偷偷重生成。剪辑局部重做与恢复保留历史。选定一季正式成片后交付一个可校验的包。团队成员按明确权限协作，个人作品须由真实所有者明确授权复制至有写权限的团队。

不新增成本、次数、项目或集数额度；保留真实模型能力、权限、输入协议与必要运行调度。面向C端，复用既有字体、配色、导航、空/加载/失败/原请求恢复交互和手机布局。禁止生产部署、真实付费调用、未经授权的外部平台发布。Spec与验收随代码入仓。
