# CC1/CC2：道具资产与跨集影响

2026-11-13，本地阶段；工作区 `/workspace/ai-creative-studio-creator`，分支 `feat/creator-completion`，基线486ef47。画布/数字人改动独立保留在另一分支的4cf33ad，没有混入本阶段；尚未推送或部署。

## 实际实现

CC1新增独立 `prop` 道具卡，记录外形标记、尺寸、材质、剧情用途、当前状态及连续性备注；使用现有不可变版本、授权声明、历史预览与固定项目绑定，不再让道具伪装成商品或场景。新字段 `Card.Prop` 为omitempty，不改变旧卡的序列化形状和内容摘要；混合卡或错配类型拒绝。

同时核查发现，商品与场景虽然可以建卡和绑定，既有 `compileLibraryInputs` 与前端选择器只允许角色/画风/声音。已让商品、场景、道具走实际视觉生成的明确文字/参考方式，完整发送对应字段和禁止变化项，保留版本固定、对应用途声明、派发前复核及结果来源。声音仍仅原生音色合同，不把声音意图朗读成对白；参考图不等于锁脸或道具细节质量验收。没有调用真实模型或增加成本/项目额度门槛。

CC2增加 `GET /api/v1/library/assets/{assetId}/impact`，按当前空间内**已记录的固定绑定和媒体来源**只读分页查询：作品/系列/季/集、固定版本、绑定数、来源素材数、旧版本提示，以及当前归档/用途声明状态。20条默认分页、最多100条是查询工作集，不是作品额度。文件端分批构建结果；PG使用同租户项目与媒体联接、JSON来源筛选及分页，不先加载整个媒体快照。不自动替换引用、重做、更新作品或发布。

入口位于资产卡上方可展开的“资产引用与影响”；用户主动查询，支持错误、重试和更多页。旧无可信来源记录不会推断关联，未记录的历史衍生物及完整活动任务/所有跨集依赖图仍非该接口覆盖范围，明确通过 coverage 和界面提示说明。新版本及用途声明在翻页时变化，要求重新读取，不能把旧表当作自动修改依据。
