- 先读 README、本轮 [产品](iteration-6-product.md)、[架构](iteration-6-architecture.md) 和 [验证](iteration-6-verification.md)。实际合同见 `api/openapi.json`，旧总架构中的描述以代码为准。
- React/TypeScript/Vite 与 Go/Eino 分离，保留图像、剧本、分镜的持久幂等和乐观版本语义。分镜保留来源剧本版本，编辑过期计划不能清除过期提示。
- 用户选择的是“真实AI创作接入”和“短剧成片全链路”一起实现，不是仅调研或单个接口。阶段为安全媒体基础、真实适配、资产/编辑/历史/时间轴、本地合成导出与完整回归。
- 默认模拟；供应商方向已要求覆盖 OpenAI、Claude、Gemini、字节、MiniMax、即梦及 Nano Banana 相关生态，只允许官方 API，区分厂商/模型/消费产品并准确披露能力矩阵。具体模型、账号和预算仍未提供。配置就绪不代表远端认证或质量已验证，外部执行结果不明可能已经计费，不自动重发。
- OpenAI/Gemini/方舟/MiniMax图像适配接受可选参考图片和角色描述，只能提供尽力外观约束，不承诺跨镜头身份一致。Google/Nano Banana有generateContent和Interactions独立适配，须按模型选择。本地合成素材只能证明媒体链路，不得包装为真实模型产出。
- 没有企业认证、租户隔离或完整账户计费；必要的上传、资源限额、外部URL与重复请求保护仍不能省略。

## 当前实现入口

- `provider_registry.go` 管理能力矩阵与显式模型配置，`provider_native_text.go` 提供 Anthropic/Gemini 原生文本及 MiniMax 文本协议；不支持的媒体能力明确拒绝，不把文本兼容协议套到媒体端点。
- 项目页面新增分析澄清、历史回滚、镜头增删排序和素材成片。照片编辑是浏览器旋转/居中方裁后保存新PNG，不是模型编辑。
- 时间轴为顺序镜头、每镜单配音/音效、全片音乐和逐句字幕；H264/AAC MP4 640×360 24fps，本地FFmpeg需要安装。源视频原音不自动保留。当前媒体及历史等独立数据文件也在DATA_DIR内，完整备份不可只拷贝主state.json。
- 演示素材是色块、正弦音和字幕。真实协议需显式模型/凭据；所有本地fake测试均不能作为真实质量或费用证明。

## 剩余实现与验证区分

最新完整矩阵与配置项见README、`.env.example`和实际registry：文本/图片理解五家，图像五家，参考图四家（即梦除外）；视频OpenAI/Google Interactions/方舟/MiniMax；语音OpenAI/Google Interactions/MiniMax/独立豆包TTS。即梦参考图官方仅URL，需要未获授权的公网素材桥接；旧视频接口下线未接入。Google视频未实现首帧/视频编辑，不宣称通用型号兼容。

字幕支持逐句手工cue、按文本长度估算和OpenAI `whisper-1` ASR时间戳候选；估算不识别音频，ASR默认不可用、候选须人工应用保存，不承诺自动强制对齐或口型同步。音乐音效是素材上传与混音，不含生成式音乐模型。照片编辑仅旋转/居中裁剪，角色参考不保证身份一致。

真实认证、选定模型权限、效果、一致性及费用未验证。provider/model守卫、精确媒体资产回执、取消和原任务恢复不可削弱；视频与即梦图像显式恢复仅查询已持久上游ID，不重新生成。没有持久上游ID时不能通过重发声称恢复。
