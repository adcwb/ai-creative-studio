## 最小上下文

- 读 `README.md`、`docs/roadmap.md`、`docs/iteration-5-architecture.md` 和 `docs/iteration-5-verification.md`；接口以 `api/openapi.json` 为准。不必重新通读历史轮次。
- React/TypeScript/Vite 与 Go/Eino 分离。图像功能保留；短剧为项目/需求 → 两角色三场模拟剧本 → 三镜模拟计划 → 逐镜编辑保存。均明确标注程序模拟，无真实文本模型、分镜图片、音视频或时间轴。
- 一项目一份当前分镜；镜头引用来源剧本版本与 1-based 场景序号。`script_version` 仅在剧本保存/生成成功时增加；分镜保存与项目需求修改不增加它。编辑过期计划不改来源版本。
- 项目共用乐观版本和持久幂等回执。剧本/分镜任一活动生成都锁定项目写入；失败保旧稿/旧计划。结果不确定的前端请求保留原 body/key，冲突不自动覆盖草稿。
- 文件快照 v3，完整 v1/v2 自动升级；已有剧本初始化 script_version=1。升级前停服备份整个 DATA_DIR，旧二进制不支持直接读取 v3。mock running 重启继续排队；图像真实调用中断不自动重发。
- 分镜 API 支持 1–30 镜，界面只编辑现有镜头；每字段限制与总请求64KiB限制同时适用。`[mock-fail]` 放入并保存某场剧本 action 可测试分镜失败保旧计划。
