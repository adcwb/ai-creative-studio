# 第五轮协作与执行边界

基于已发布并验证的 `b080d6bfe9e48f1066b2beb37f530fa5eaa28247`，在保存的云工作区安全快进后创建 `feat/storyboard-plan`。先前只读规划时本地只有第二轮，未声称取得未发布第四轮代码；收到准确基线与实施授权后才开始本轮修改。

| 职责 | 实际执行者 | 文件与交付 |
| --- | --- | --- |
| 产品收敛、集成、最终审阅 | 主代理 | 与契约角色冻结范围；README、路线图、品牌、CI 检查入口与精简交接；原图像/剧本回归、提交 |
| 后端 | backend 子代理 | Go 模型、共享存储、迁移、Eino、HTTP、并发与恢复单测 |
| 前端 | frontend 子代理 | TypeScript 契约、编辑/轮询/草稿保护、品牌界面和单测 |
| 产品与架构契约 | contract 子代理 | OpenAPI、真实 HTTP 契约检查、产品与架构文档 |
| 独立测试 | qa 子代理 | 分镜 E2E、实际进程恢复、布局测量、合成截图和验证记录 |

代理共享一次基线核查，按文件归属分工并直接协调字段与测试选择器；未重复委派全仓阅读。主代理检查后端事务/深拷贝/版本守卫及前端来源语义，发现对白可空字段的存在性校验与契约不一致后，由后端和契约角色统一。

全程仅本地模拟与合成演示数据。未推送、部署、调用付费模型、配置真实凭据或变更权限。旧的连续开发/发布对话不覆盖本轮明确的“不推送”限制。应用依赖版本未升级；安装中实际出现 ESLint 9.39.1 停止支持提示，未因此扩大范围。首次 npm 默认缓存目录不可用，改用 `/tmp/studio-npm-cache` 后安装完成。

最终检查以 [验证记录](iteration-5-verification.md) 为准；新增 CI 步骤只本地编写，本轮未发布，不能宣称第五轮已通过远端 CI。
