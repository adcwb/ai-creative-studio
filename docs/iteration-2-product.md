# 映创第二轮产品增量与验收标准

本轮在基线 `7284fab759ee6f59d1e75ab1b1c1dc13b34fba58` 上进行本地迭代。本文定义产品范围与可测试目标，不代表这些目标已经通过验证；实际结果由独立测试记录说明。本轮不推送、不创建 PR、不部署。

## 目标与范围

让用户完成一条由真实业务后端支撑的创作路径：读取模板 → 调整描述、比例与风格 → 创建任务 → 查看详情 → 失败后编辑重试 → 保存素材 → 搜索和筛选已保存素材。

本轮采用用户追加的完整闭环要求：所有纳入范围的业务操作必须有真实后端 API、校验、业务逻辑、持久化、错误路径和前后端联调验证。浏览器中的草稿与筛选输入只是交互状态，不能冒充后端记录或成功结果。AI 图像 provider 仍然是 mock，但模板目录、任务创建与执行调度、重试关联、素材保存和查询均须实际运行。

保留“映创”中文品牌、现有个人/团队演示空间与响应式工作室。本轮仅扩展已有图像创作流程，不增加真实模型、付费调用、照片上传、肖像编辑、短剧/漫剧、任务取消、批量生成、素材删除、成员管理或生产认证。所有结果继续是带“模拟图像 · 非 AI 生成”标识的程序绘制 SVG；比例和风格只表达模拟参数，不代表真实模型效果。

| 本轮交付 | 用户价值 | 实施边界 |
| --- | --- | --- |
| 三类创作模板 | 从明确的起点开始，减少空白输入成本 | 海报、肖像概念、通用创作；后端只读目录提供模板与参数选项，不建设模板管理后台 |
| 比例和风格参数 | 用户能控制并核对创作设定 | 三种比例、三种风格；服务端校验并持久化 |
| 任务详情 | 查看完整描述、参数、阶段、结果或错误 | 调用已有详情 API 读取真实记录，不新增独立项目实体 |
| 失败后编辑重试 | 修正失败原因，保留尝试历史 | 专用重试 API 创建、持久化并调度关联任务，保留原任务 |
| 素材搜索与类型筛选 | 找到当前空间保存的结果 | 后端查询真实持久化素材，组合关键词与类型条件 |

## 创作设定

与架构角色对齐后的字段和可选值如下；前后端、OpenAPI 与测试使用相同枚举。

| 字段 | 可选值 | 界面含义 |
| --- | --- | --- |
| `kind` | `poster` / `portrait` / `general` | 创意海报 / 肖像概念 / 通用创作 |
| `ratio` | `1:1` / `4:5` / `16:9` | 方形 / 竖版 / 横版 |
| `style` | `natural` / `studio` / `illustration` | 自然 / 棚拍 / 插画 |
| `prompt` | 去除首尾空白后 3–1000 个 Unicode 字符 | 用户完整画面描述 |

前端从 `GET /api/v1/templates` 读取模板与选项，不维护另一份硬编码模板列表或在读取失败时伪造成功目录。模板选择应同时填入描述、类型、比例和风格，不立即提交；提交时由后端再次校验并持久化。用户仍可修改所有设定。模板只提供起点，不保证图像质量或真实肖像效果。

| 模板 | 默认参数 | 建议描述方向 |
| --- | --- | --- |
| 创意海报 | `poster`、`4:5`、`illustration` | 春日咖啡品牌、奶油色背景、柔和光影、标题留白 |
| 肖像概念 | `portrait`、`4:5`、`studio` | 职业人物概念、简洁背景、自然神态、棚拍氛围；不上传照片 |
| 通用创作 | `general`、`1:1`、`natural` | 清晨山间景观、层叠山峦、柔和自然光 |

比例须改变新生成 SVG 的实际画布比例，预览保持原始比例，不能仅改变下拉框文案。风格须保存在任务与素材中，并在模拟结果的文字或视觉处理上可观察。明确的字段标签应支持键盘操作和辅助技术，不能仅用图标或颜色区分选项。

## 用户路径与状态

### 首次创建与保存

1. 用户进入当前演示空间，看到模拟 provider 说明以及模板/任务加载状态。目录加载失败时有明确错误与重新加载入口，不用前端静态模板掩盖失败。
2. 选择一个模板，核对并修改描述、比例和风格。
3. 提交后出现任务；创建请求进行中不能重复提交。任务继续自动更新，状态为等待执行、模拟制作中、模拟完成或执行失败。
4. 用户打开任务详情，实际请求详情 API，看到完整描述、类型、比例、风格、创建时间、状态，以及结果或错误。关联重试任务显示来源任务 ID。排队/执行中仍展示阶段进度；当前进度是流程阶段，不暗示真实模型完成百分比。请求中与请求失败均有独立状态。
5. 成功任务可保存到当前空间素材库。保存中有反馈，重复保存不新增素材，已保存状态可以辨认。
6. 打开素材库，查看结果和参数，用关键词及类型找到所需素材。

任务详情可以采用内嵌面板、抽屉或对话框；若采用对话框，需有可访问名称、明确关闭按钮，支持 Escape 关闭并合理恢复焦点。详情内容较长时可滚动，移动端不产生横向溢出。关闭详情不应清除创作草稿。

### 失败后的编辑重试

失败任务提供明确的“编辑后重试”入口，将完整创作设定回填到表单，并显示当前在重试哪个失败任务。用户能先查看和修改内容，再提交。回填保留原始描述，包括用于故障演示的 `[mock-fail]`，不静默删除内容。如果用户保留该标记再次提交，模拟失败是预期行为；移除后可验证恢复路径。本轮不要求成功任务的复用入口。

编辑重试提交 `POST /api/v1/tasks/{id}/retry`，使用新的幂等键及完整编辑后输入，由后端创建并调度新任务。新记录持久化 `retry_of` 为直接父任务 ID，原任务及其失败状态保持不变。同一次重试请求在超时或网络错误后再次发送时继续使用原幂等键，避免产生重复执行尝试。重试任务若再次失败，可继续重试，形成直接父任务关联。

仅失败任务可重试；对等待中、执行中或成功任务调用重试 API 返回冲突。不存在或跨空间的父任务返回 404。使用同一个键改输入、改父任务或与普通创建混用均不能悄悄产生新任务。用户可退出重试编辑，恢复普通创建；提交前始终能看清当前内容和操作类型。

### 素材搜索与筛选

搜索对象为当前演示空间的真实持久化素材，前端将条件提交给 `GET /api/v1/assets?space_id=…&q=…&kind=…`。后端按完整 `prompt` 做子串匹配；关键词去除首尾空白，最多 100 个 Unicode 字符，英文字母匹配不区分大小写。类型选项为“全部 / 海报 / 肖像概念 / 通用”，选项与后端目录一致。关键词与类型以“同时满足”组合，空关键词等价于不限制关键词，“全部”不传类型约束。

显示本次后端查询的匹配数量，并区分“还没有素材”“没有匹配素材”与“查询失败”；无匹配时可清空条件。清空条件重新查询当前空间全部素材，不改变任务或素材。查询中有反馈，快速改变条件时旧响应不能覆盖当前条件的结果。筛选不改变已有素材的排序。切换空间时不显示前一空间的任务、素材、详情或错误；搜索与筛选可随现有空间重挂载机制重置。搜索状态不影响任务的“已保存”判定，已保存素材被过滤隐藏后也不能被当成未保存。

## 契约与兼容要求

- `GET /api/v1/templates` 返回后端权威目录：`{templates:[{id,name,description,kind,prompt,ratio,style}],ratios:[{value,label}],styles:[{value,label}]}`。模板 ID 为 `poster`、`portrait`、`general`，与 `kind` 一致。本轮目录为后端只读配置，不要求可编辑目录的数据库或管理 API；用户选择的最终参数必须保存在任务和素材中。
- 普通创建继续使用 `POST /api/v1/tasks?space_id=…`，输入为 `prompt`、`kind`、`ratio`、`style`。任务列表、真实详情 API 及保存后的素材返回一致的已规范化设定。
- 旧客户端遗漏或传空字符串的 `ratio` / `style` 分别使用 `4:5` / `natural`，输出应为非空值。选择 `4:5` 是因为第一版 SVG 实际画布为 800×1000，避免将历史结果标错比例。第一版 `kind` 校验行为保持，新增 `general`。
- 旧持久化任务和素材读取后具有上述默认参数，原结果 SVG、ID、空间归属与保存关系保留；重新启动后能继续读取。兼容处理不能清空或重建历史数据。
- 未知的非空比例、风格或类型应返回明确的输入错误，不入队、不生成素材。描述仍按 Unicode 字符校验。
- 幂等比较覆盖规范化后的四项设定。相同空间、相同键和相同设定返回同一任务；相同键但任一设定不同返回冲突。遗漏默认值与显式传入默认值应视为同一设定。
- `POST /api/v1/tasks/{id}/retry?space_id=…` 接受完整输入和 `Idempotency-Key`；只允许当前空间的失败父任务。首次成功返回 202 与新 queued 任务，正确重放返回 200 与同一任务。新任务持久化直接父关联 `retry_of`，进入现有 worker 的真实执行队列；普通创建不带该关联。原任务不被修改。父任务不存在/跨空间为 404；非失败父、同键改父/改输入/与普通创建混用为 409。关联及幂等语义需在重启后保持。
- 保存素材继续使用已有保存接口；只允许成功任务保存，返回的描述、类型、比例、风格与来源任务一致，重复保存仍只有一份。
- `GET /api/v1/assets` 在服务端对持久化素材组合应用 `q` 与 `kind` 条件。`q` 去首尾空白后超过 100 个 Unicode 字符或非空 `kind` 不属于三种枚举时返回 400；没有匹配时返回空数组。查询不能返回其他空间素材。本轮不增加分页、排序参数或新的数据库。
- 空间过滤沿用现有服务端规则，仅作演示数据归属，不宣称认证或租户安全隔离。所有失败均展示真实错误，不能在后端失败后用浏览器内记录伪装提交、保存、详情读取或查询成功。

## 可测试验收标准

以下场景构成本轮完成条件。功能相关 API/持久化断言由后端测试覆盖，实际界面路径由浏览器测试覆盖；测试应使用独立临时数据，避免污染正常开发数据。

| 编号 | 场景 | 预期结果 | 验证层 |
| --- | --- | --- | --- |
| P01 | 读取目录并分别选择三个模板 | 真实目录 API 返回三模板和合法参数；UI 使用该响应同时回填描述与参数，仍可编辑，选择本身不提交 | API + 浏览器联调 |
| P02 | 创建通用、横版、自然风格任务 | 请求接受，列表与详情参数一致，成功 SVG 画布为 16:9 且保留模拟标识 | API + 浏览器 |

| P04 | 使用无效类型、比例、风格或超长描述 | 返回明确输入错误，没有新增任务；界面保留草稿并展示错误 | API；描述由浏览器补充 |
| P05 | 同键重复提交；再保持键修改任一参数 | 相同设定仅一条任务；变化的设定冲突；默认遗漏与显式默认值等价 | 后端/API |
| P06 | 查看排队、成功、失败与重试任务详情 | 实际详情请求返回完整记录；描述、参数、阶段、关联、结果或错误可见，成功才可保存 | API + 浏览器联调 |
| P07 | 重试非失败任务、跨空间父任务，或同键改变输入/父任务/操作类型 | 分别返回 409/404 等约定错误，不新增任务或篡改父记录 | 后端/API |

| P09 | 保存成功任务两次，刷新后读取 | 仅一份素材，四项设定与任务一致，刷新后仍存在 | 后端 + 浏览器 |
| P10 | 关键词搜索、类型筛选及组合筛选 | 真实查询 URL 携带条件，后端仅返回匹配持久化素材；子串、英文大小写、计数正确，清空重查恢复全部；非法参数400 | API + 浏览器联调 |
| P11 | 目录/详情/重试/保存/查询失败，随后恢复；查询无匹配 | 错误有明确反馈，保留可恢复草稿，不伪造成功；无匹配与错误可辨认；恢复后可继续使用 | API + 浏览器错误路径 |
| P12 | 在查看详情或筛选素材时切换空间 | 无旧空间内容闪回；目标空间正确加载，跨空间查询/保存仍返回 404 | 浏览器 + API |
| P13 | 使用第一版状态及新增重试/素材状态重启 | 旧数据默认 4:5/natural、原 SVG/ID 保留；新重试关联与幂等仍有效，素材查询从持久化数据正确返回 | 持久化/进程测试 |
| P14 | 桌面与约 390px 手机宽度操作 | 核心创建、详情、编辑、搜索路径可操作，无横向溢出，表单标签及焦点行为可用 | 浏览器 |
| P15 | 快速更换筛选、切换空间或打开不同详情 | 延迟旧响应不覆盖当前查询/详情；过滤隐藏素材不改变已保存事实 | 浏览器 |

本轮继续保留第一版的服务错误处理、空间归属、恢复、重复保存与幂等保障。验收不包括真实模型生成质量、成本准确性、照片隐私、生产认证授权或公共部署能力。只有本地实现及独立验证完成后，才可在后续明确授权范围内讨论发布。

## 集成后的产品代码复核

2026-10-22，产品角色只读核对前端组件、工作区状态逻辑、后端 API/存储/worker 与独立测试代码；没有占用 QA 的 5174/8081 端口，没有把代码审查当作浏览器测试通过。实际执行结果以 [第二轮验证记录](iteration-2-verification.md) 为准。

| 验收项 | 代码复核结论与证据 |
| --- | --- |
| P01–P03 | `catalog.go` 提供三模板与参数；`TemplateGallery` 和 `Composer` 消费实际目录；`pipeline.go` 按比例改变 SVG 画布，类型与风格改变图形处理，保留模拟标识。 |
| P04–P05 | `Normalize`、HTTP 参数解码和 `createLocked` 校验输入与归一化幂等。前端草稿在请求失败后保留，后端结果返回前不伪造任务。 |
| P06–P08 | `TaskDetail` 独立请求真实详情；`Retry` 只接受当前空间失败父任务；新记录持久化 `retry_of` 并由 worker 执行，原记录不改。失败回填保留故障标记，取消编辑恢复编辑前草稿且不发送 POST。重试成功后的编辑状态收口见下方记录。 |
| P09–P10 | `SaveAsset` 保存完整参数并去重；素材关键词/类型由真实 API 在持久化仓库数据上组合筛选，浏览器没有本地过滤代替服务端查询。 |
| P11 | 模板失败时显示错误并禁用提交，详情、重试、保存、查询均有真实错误反馈。素材加载、空库、无匹配与失败分别呈现；服务恢复的实际执行结果以独立验证记录为准。 |
| P12–P13 | 工作区以空间 ID 重新挂载，旧查询/提交带取消信号；后端再次按空间校验。旧快照默认参数、重试关联与幂等恢复有实现和独立持久化测试，实际进程结果见验证记录。 |
| P14–P15 | 详情使用原生对话框并恢复焦点；素材请求以查询条件标识结果，旧请求取消；已保存状态来自独立全量素材集合，不随过滤结果消失。桌面/手机布局与竞态行为需以 QA 的实际浏览器断言为准。 |

能力文案符合范围：保留映创品牌；短剧/漫剧只显示“规划中 · 暂未提供生成能力”，没有生成按钮或伪成功交互；显式说明模拟 SVG、无生产认证、空间不构成权限隔离。关闭详情、取消编辑与开始新创作均只是界面操作，不取消任何已提交后端任务。

产品复核反馈已在代码中解决：`App.tsx` 的 `submitDraft` 仅在重试 API 获得成功响应后退出原任务编辑并恢复空白创作表单，新任务继续在记录区更新，成功通知说明原任务保留。`useWorkspace.create` 在网络失败、响应丢失或卸载取消时返回失败，不触发该清理，因此草稿与当前重试幂等键可继续用于安全重放。取消编辑仍恢复编辑前草稿，不执行后端取消。此结论来自修复后的代码复读，浏览器回归结论仍以独立验证记录为准。

产品文档已冻结；代码复核范围内没有剩余产品阻断项。最终交付仍需结合独立运行验证，不据此宣称 P01–P15 的所有浏览器场景已经通过。
