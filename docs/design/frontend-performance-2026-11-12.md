# 前端加载与读取优化记录

## 结果

| 生产构建 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 主 JavaScript chunk | 592.38 KB | 364.82 KB |
| 主 chunk gzip | 199.80 KB | 118.26 KB |
| 英文按需 chunk | 包含在主包中 | 230.48 KB / gzip 82.43 KB |

主包减少约 38%，gzip 减少约 41%，不再触发 500 KB chunk 警告。英文用户仍需下载英文词典；此结果不代表英语总下载量减少，也不是首屏耗时基准。

## 实现

- `englishDictionary.ts` 保留原词典覆盖顺序，通过 `loadLocale` 动态加载。中文启动不请求词典，英文首次启动在词典就绪后挂载内容。切换语言不卸载已有工作区，最后一次选择生效；加载失败可以重试或切回中文。
- `usePolling` 和可独立测试的调度器用于图像任务、任务详情、剧本生成、创作工具、媒体剪辑、镜头制作、数字人、预演历史。请求结束后安排下一次读取；页面隐藏暂停并取消读取，恢复后刷新；瞬时错误指数退避至 30 秒，权限类错误停止。已有终态停止条件保留。
- 图像任务和素材读取限定在 `/studio` 与 `/assets`。父控制器继续保存跨页面草稿和 uncertain 提交的幂等标识。公共调度器只处理读取，不重试或取消写入。
- 模型目录按账号、空间、功能合并并发请求，成功结果缓存 15 秒，最多保留 64 个键。手动刷新、会话变动和模型/网关/绑定配置写入使缓存失效；一个 picker 卸载不取消其他 picker 的共享读取。
- 对时间线、剧本、分镜的大对象 dirty 比较按依赖缓存；读取取消与 epoch 检查防止旧结果覆盖新上下文。
- 列表图片增加懒加载、异步解码及重点列表占位；保留首屏品牌和当前编辑预览的及时加载。登录错误、网关凭据校验与字段关联，提示词对话框关闭后恢复焦点。

## 验证

- `npm run build`：TypeScript 与生产构建通过。
- `npm run lint`：零警告。
- `npm test`：24 个文件、78 项测试通过；覆盖轮询取消、不重叠、终态、权限失败、退避上限，以及缓存去重、隔离、过期、失效和原有幂等请求合同。
- `node scripts/i18n_check.cjs`：2795 条文案覆盖通过。
- 完整路由浏览器回归：桌面与移动端共 82 项通过、2 项按设备条件跳过，包含弹窗、键盘焦点、主题对比度、跨页面幂等恢复、制作与剪辑流程。
- 生产构建额外运行 `performance.spec.ts`：桌面与移动端共 12 项全部通过，验证真实分包入口、语言加载失败恢复、快速切换、隐藏暂停与目录去重。

浏览器使用 Chrome，API 使用本地合成 fixture。测试证明前端交互和请求生命周期，不证明真实上游模型效果。Windows 本次将 fixture 与 Vite 分别启动，并设置 `PLAYWRIGHT_ROUTING_EXTERNAL=1`，避免测试框架结束时等待服务进程树关闭。
