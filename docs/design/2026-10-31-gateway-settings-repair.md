# 网关、导航与后端配置改进

用户已确认实现范围。沿用森林工作室的配色、字体、分组布局，不更换视觉系统。

- 收起导航使用同一图标中轴，移除子组缩进与竖线；固定图标宽度，保持点击与键盘操作。
- 网关列表使用独立操作样式；表单明确保留、设置、撤销凭据，未配置加密时可保存连接。凭据不回显。
- 单机文件存储首次启动生成私有持久密钥；显式环境变量或共享密钥文件优先。已有密文而密钥丢失时拒绝替换。数据库独立 worker 必须共享显式密钥。
- 模型目录同步复用 GET /models。导入去重、原子保存、版本校验，保留既有配置。新模型先停用，待确认能力与价格。每个网关可选择关闭或定时同步，服务端调度，不依赖页面停留。
- 后端全局配置由环境变量 STUDIO_ADMIN_EMAILS 中的部署管理员维护；不会从组织角色推导。私有 JSON 配置文件在 API/worker 启动时加载，文件配置优先。位置、部署管理员、认证模式和加密主密钥不能通过网页改写。敏感字段只写，保留/替换/清除显式区分。保存不自动重启进程。

验证：配置补丁、脱敏、权限与版本冲突测试；目录同步去重、失败不修改、配置保留测试；实际 HTTP 合成目录；桌面/手机布局回归；前端 lint、类型检查、构建及相关测试。更新既有 OpenAPI 与部署说明。外部真实网关不在验收中。
