## 验证与边界

已通过：Go 全包 race（真实 PostgreSQL、队列、worker、备份恢复）/ vet / build、计划备份测试；前端类型 / lint / 48 单测 / build / 1618 条 i18n 静态检查；22 项真实 API 认证浏览器测试；2 项真实 API + 假上游网关 Key 浏览器测试；6 项最终截图重跑；443 个 OpenAPI 响应契约、安全契约、实际媒体/4K、恢复、对齐与 Python/本地模型契约；90 个布局状态。46 项完整路由重跑通过（数字人单项另六次通过）；真实 PostgreSQL 的 22 项认证浏览器、2 项报价、multi-service 与 managed-eval 演练通过。94 项通用 E2E 最终整套通过（8.9 分钟）。全部账号、图片、Key、上游响应及模型测试素材为合成数据。报价测试使用真实 PostgreSQL 和 API，但不启动供应商执行 worker；managed-eval 演练只在测试进程内替换候选计划读取为合成计划，生产 CLI 的精确已审核计划与预算授权检查未取消。

容器构建尝试：默认 buildx 状态目录只读后，将工具状态目录放在 `/tmp`；随后 backend `RUN go mod download` 在 `https://proxy.golang.org/...` 返回 `tls: failed to verify certificate: x509: certificate signed by unknown authority`。没有关闭 TLS、修改安全网络配置或替换镜像来源。该阻塞发生在构建阶段，因此当前源码的双容器验收未运行，历史 CI 通过不能替代它。

探索性浏览器运行曾受容器网络变化影响：trace 中模块加载 `ERR_NETWORK_CHANGED`；该次运行停止后以最终源码重新完整运行，不计作通过。旧侧栏语言定位和布局断言改为系统设置入口，保持语言持久化和可达性断言。网关报价夹具显式建立功能绑定并允许本次模型选择，不放开产品授权。

当前 CORS 既有策略回显非空 Origin 并允许凭据（项目原有设计），此次仅补 PATCH；并未实现来源白名单。真实密钥、供应商收费调用、生产迁移、SSO 与社交发布均未执行。个人偏好不宣称跨设备同步；不同厂商专用协议不自动转换为 OpenAI-compatible。
