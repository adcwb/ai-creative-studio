# 显式运行时模型选择

创作请求携带 `model_config_id`、当前 `model_config_version`，语音合成另需 `voice`。服务端从已认证会话绑定租户与 actor，校验模型启用状态、凭据、实际能力和功能授权；请求不能指定其他租户、actor、端点或凭据。

成本管理已移除：不要求价格、报价、费用确认、预算或单次上限，不创建费用预留，也不读取旧额度决定是否执行。兼容接收旧 `budget_currency`、`budget_maximum_minor` 与 `quote_request_sha256` 字段，但执行时忽略。旧报价接口仅为兼容保留，报价失败不影响调用；正式页面不调用它。

`GET /api/v1/runtime-models` 仅返回当前组织的模型与可用状态，不返回 secret、引用名称、端点或管理历史。缺少价格不影响可用性；只读成员仍不能执行。配置修改、停用、撤销和成员权限变更会在实际发送前重新校验。

内容审核仍独立生效。缺少或过期的审核配置会令目录显示“内容审核未就绪”；输入或输出审核拒绝时，不提交或不发布相应结果。审核配置见 [执行治理](execution-governance.md)。功能绑定及“允许本次切换”仍控制模型选择。DeepSeek 文本模型不因成本管理移除而具备图片或视频生成能力。

文件和 PostgreSQL 模式均在网络发送前持久化无金额的执行凭证，防止同一任务重复提交。新 PostgreSQL 表 `studio_model_dispatches` 需由既有 schema 迁移流程创建；任务与队列的原子提交保持不变。历史预算／账单数据原样保留；已发送或结果未知的旧任务不能自动重放。已选择模型的固定每小时 20 次费用配额已取消；并发、请求大小、输出格式、超时及存储容量等资源保护仍保留。

`scripts/postgres_browser_check.py --acceptance-fixture ...`（兼容别名 `--quote-fixture`）使用全新合成数据库、不配置价格和预算、不启动模型 worker，验证图像和素材任务无报价入队。正常模式运行独立 worker 的完整安全浏览器套件。`playwright.gateway.config.ts` 另用本地 HTTP 合成上游验证图像、剧本、分镜和镜头图片的完整生成。所有测试都不使用真实供应商凭据或付费调用。

即梦凭据仍须为含字符串 `access_key`、`secret_key` 的完整 JSON 对象，整体加密保存；不自动联网检测。
