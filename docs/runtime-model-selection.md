# 显式运行时模型选择

组织模型配置不再只是管理声明。图像任务、剧本、分镜、项目创作与字幕 ASR 接收层支持 `model_config_id` / `model_config_version`；服务端从当前会话提取 actor 与 tenant，解析配置后把完整执行绑定保存到任务。客户端传 `runtime_selection` 或 `actor_id` 会被拒绝。原始执行绑定不出现在 HTTP 响应中，历史供应商、型号与结果保持可读。

省略模型选择仍使用已有本地／模拟路径；保存组织默认项不会把现有按钮变为付费操作。前端各生成入口可显式选择模型，普通成员通过 `GET /api/v1/runtime-models?space_id=...` 读取脱敏目录，不需要管理员配置权限。目录不返回 secret、引用名称、endpoint 或管理历史；只读成员不能执行。

选择必须携带正整数配置版本和明确的 `budget_currency`、`budget_maximum_minor`。费用为原币种整数最小单位，不兑换；提交前 UI 展示可信上限、来源和有效期并要求确认。执行器重新取得报价后拒绝币种不同或超出用户上限的请求。配置修改／停用／撤销后旧版本不能继续提交；运行时还会在实际发送前重新检查权限与版本。

当前无需完整任务输入即可发布的报价限于部署者配置的 `text-64k-6000-v1` 有界文本合同：OpenAI／Anthropic、完整请求大小及输出上限均由执行层限制。目录仅读取本地受信策略，绝不探测供应商。`POST /api/v1/runtime-quote` 为图像、剧本、分镜、创作与 ASR 构造与 worker 相同的请求，精确绑定参数、声音和素材内容哈希。前端获取当前请求报价并确认后携带 `quote_request_sha256` 提交；修改输入或版本必须重新报价。预览不调用供应商、不预留费用；没有匹配的可信规则则拒绝。图像、视频、语音和 ASR 精确价格不冒充通用报价。适配器和配置存在不代表真实账号权限或效果已验证。

文件模式的任务创建与费用预留仍不是同一存储事务；费用执行层默认拒绝缺报价、缺审核或缺持久账本的请求。不要把接收任务成功称为上游已受理或已付费。独立 worker 使用 `ConfigureManagedRuntime` 安装相同授权边界，不需要 HTTP 服务器，也不从本地机器自动读取供应商 secret。

测试使用合成账号、合成加密凭据、内存/本地协议 fixture；没有读取真实 secret、真实供应商调用或付费验收。

本地验收：`scripts/postgres_browser_check.py --quote-fixture ...` 创建独立合成 PostgreSQL 数据库，安装两条精确请求价格规则与拒绝执行的本地审核脚本，不启动 worker。桌面／手机均验证图像与项目素材的获取报价、原币种确认、输入修改失效及任务接收；该测试证明接收闭环，不证明真实生成完成。正常模式不带此标志则运行独立 worker 的完整安全浏览器套件。两类模式均不使用真实供应商凭据。

即梦凭据编辑需提交完整 JSON 对象（字符串字段 `access_key`、`secret_key`）；整体在服务端加密保存。未知字段、尾随 JSON 和单密钥均拒绝，界面提供简中／英文帮助，不自动联网检测。
