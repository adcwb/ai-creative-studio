# 第四轮前端与交互

本轮在 `7dab4ea` 上新增短剧工作台，沿用映创 SVG 品牌、深绿与暖白 tokens。只在本地实现和验证；没有推送、部署、密钥输入或付费文本调用。

## 页面结构与真实数据

默认入口仍为图像工作室。顶栏新增可键盘访问的“图像工作室 / 短剧工作台”导航，手机也可直接切换。短剧工作台使用独立 `DramaWorkspace`、`DramaScriptEditor`、`GenerationHistory` 组件以及 `drama.css` 命名空间；原 `.creation-grid`、`.composer`、`.results`、全高侧栏轨道和图像响应式规则保持不变。

同一空间内切换到短剧时，图像工作室实例通过原生 `hidden` 隐藏而不卸载，保留图像草稿、失败任务编辑上下文及未确认请求的幂等键；返回后可继续原操作。隐藏工作室不进入可访问导航或键盘焦点。切换空间仍按原有行为重建图像工作室，避免空间间混入结果。

短剧页左侧为真实项目列表，右侧按“项目简报 → 生成 → 当前剧本”排列。宽度 ≤1100px 时项目导航置于编辑区上方；≤700px 变为单列。长项目名、简报、动作和对白换行，编辑区自然增高，不依赖固定高度裁切。角色与对白归属只读；只编辑剧本标题、梗概、三场标题/动作及已有对白文本，不新增角色或场景操作。

项目列表、详情、生成历史全部读取真实 API；创建、简报保存、生成、剧本保存全部等待真实写入响应，不在前端伪造项目或脚本。写入成功后使用服务端返回的版本。生成接受后的 202 只表示请求已保存，后续每 1200ms 读取项目详情直到终态。失败展示后端错误及代码，旧稿保持可读。

短剧顶栏和正文都明确 `mock-script`，不沿用图像服务的真实模型/不可用徽章。短剧操作不读取图像能力或凭据，不触发图像生成。模拟文本只能验证业务流程和数据结构，不能作为 AI 创作质量证据。手机正文也保留“无生产认证、演示空间不构成权限隔离、勿输入敏感信息”说明。

## 草稿、幂等与冲突

- 项目简报和剧本不能同时编辑，避免保存其中一项无声覆盖另一项草稿。简报有未保存修改时不能生成或编辑剧本；剧本编辑期间简报锁定。取消相应编辑恢复已读取内容，不发写请求。
- 所有写入携带 UUID 幂等键；修改和生成携带当前已读取的 `expected_version`。同一次写请求未确认时锁住修改，保留完整 body/path/key，“重试上次请求”精确重放。明确完成后，下一次生成使用新键。
- 版本、生成中或幂等冲突保留本地草稿并展示错误。显式“重新读取最新项目”说明会弃稿；仍有草稿时经确认再加载服务端版本，不自动覆盖。
- 切换项目、空间、工作台均保护脏稿；确认离开不会撤销已接受的后台请求。刷新/离开页面使用浏览器 `beforeunload` 提示，草稿没有冒充服务端持久化。
- 已有稿重新生成前，确认成功后替换当前稿、失败保留原稿。`script_brief` 与当前简报不同时标明来源是旧简报，并提供只读展开内容。
- 读取请求在切换时取消；项目编辑器按空间与项目重挂载；写请求 epoch 与单调版本检查避免旧 GET 覆盖新保存结果。重复点击由同步 in-flight 标识阻挡。
- 原生确认 dialog 支持 Escape、Tab/Shift+Tab 闭环，默认焦点放在“继续编辑”，关闭后恢复此前焦点。

生成历史来自 `GET /projects/{id}/generations`，显示真实尝试、状态、时间、来源和失败原因；它不提供旧稿浏览或回滚。

## 验证与证据

前端 `npm run lint`、`npm run typecheck`、`npm run build` 通过；本轮单元测试 3 个文件、10 项通过。图像实例保留的小修后，再次执行 lint 与包含 TypeScript 编译的 build 均通过。

QA 独立短剧布局检查通过 30 个组合：空项目、已生成、长内容、编辑中、失败 × 1280/1440/1920 桌面、低高度桌面、1040 堆叠、390 手机。实际读取 [归档几何数据](screenshots/iteration-4-project-geometry.json) 确认：30 项 documentWidth 均等于 viewport，长文裁切计数均为 0；20 个双列桌面状态项目导航与编辑区顶部一致，25 个非手机状态侧栏背景与 shell 底部一致。该检查在图像 provider 缺少凭据、ready=false 的真实后端上完成，短剧仍正常生成。

已实际查看 QA 生成态 [桌面截图](screenshots/script-desktop.png) 与 [手机截图](screenshots/script-mobile.png)：角色卡片、三个场景和对白分隔清楚，页面自然增高，手机操作按单列排列。截图使用真实业务 API 生成的合成测试项目，不是用户内容或真实 AI 创作样本。1440 桌面项目/编辑区顶部均为 370.734375px，侧栏/shell 底部均为 2790.875px；390 手机内容宽度为 390px，剧本自然延伸到页面底部。

冻结代码后的最终浏览器回归 28/28 全部通过（2.0 分钟），包括原图像流程、桌面与手机短剧闭环、保存丢响应同键重放、版本冲突保稿、草稿离开确认，以及图像草稿/未知提交跨工作台保留。原图像 24 状态布局、短剧 30 状态布局及 provider 联调均通过；具体运行与边界证据见 [第四轮独立验证](iteration-4-verification.md)。前端源码和本文已冻结，无已知阻断。
