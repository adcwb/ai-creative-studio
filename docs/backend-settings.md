# 后端配置与模型同步

左侧“系统设置 → 后端配置”（`/settings/backend`）是独立入口；“偏好设置”提供直接链接。普通账户看到部署权限说明，部署管理员看到实际配置表单。系统设置新增“后端配置”，由部署环境中的 `STUDIO_ADMIN_EMAILS` 指定可登录管理的邮箱，逗号分隔。组织所有者和组织管理员不会自动获得全局配置权限。修改部署管理员列表需要在部署端修改环境变量并重启；接口继续要求登录、CSRF 和审计。

后端原先直接读取环境变量。本版增加私有 JSON 配置文件，默认是 `DATA_DIR/backend-config.json`，也可用 `STUDIO_CONFIG_FILE` 指定固定路径。API 与 worker 在初始化服务之前加载文件，文件中的值优先于环境变量。网页保存不会重启进程；页面显示待重启项目。独立 worker 应挂载相同文件，全部相关进程重启后生效。

表单覆盖 `backend/.env.example` 的配置项。`DATA_DIR`、`AUTH_MODE`、主密钥、配置文件位置和部署管理员由部署环境管理。其他字段可修改或恢复环境值。敏感项不回显，空白输入保留已有值，通过“清除值”显式清除；“恢复环境值”删除文件中的覆盖值。数据库与认证配置错误可能导致下次启动失败，此时由部署管理员修正私有文件或移除相应覆盖。

文件权限为 0600，目录为 0700。该配置文件与传统 `.env` 一样可包含数据库、SSO 等敏感配置，不应提交 Git 或公开下载。网关 API Key 仍使用 AES 加密后保存在模型存储中。配置文件由一个 API 实例负责写入；多 API 部署应将管理请求固定路由到该实例。worker 只读取。文件中的版本摘要用于拒绝过期保存。保存会同步文件及其所在目录；如果写入结果未确认，应重新读取版本再决定是否重试。

## 网关 API Key

文件模式首次启动且没有旧密文时，服务自动在 `DATA_DIR/model-config.key` 初始化随机 32 字节主密钥，并在重启时复用。密钥先完整写入私有临时文件再原子发布，不覆盖并发进程生成的文件。不能删除此文件后继续使用旧密文；应恢复原密钥。已有密文但没有主密钥时拒绝生成替代密钥。

`MODEL_CONFIG_KEK_BASE64` 的显式配置优先。也可通过 `MODEL_CONFIG_KEK_FILE` 指定共享私有文件。PostgreSQL 与独立 worker 不会各自生成默认密钥，必须显式提供同一个环境密钥或挂载同一密钥文件。新安装可初始化共享文件；已有加密数据必须使用原密钥，不能切换到全新密钥。已有密文时，缺失密钥或提供错误密钥都会导致 API 与 worker 启动失败；尚无密文的 PostgreSQL 实例仍可在未配置密钥时保存不含凭据的声明。

主密钥独立保管，不通过网页修改，也不包含在模型逻辑导出中。备份与恢复时保留原主密钥；轮换沿用已有离线轮换工具，完成后更新环境变量或密钥文件。不要把新密钥直接覆盖旧密钥来代替轮换。

## 模型目录同步

AI 网关列表和网关模型页提供“同步模型”。模型页先选择一个具体网关。编辑网关时可设置定时同步间隔，默认关闭；调度由 API 进程每分钟检查，不依赖网页保持打开。API 停止期间不执行同步，重启后继续按持久化的上次尝试时间判断。

同步只调用网关的 `GET /models`，不产生生成请求。完整目录最多 200 个条目、响应最多 1 MiB，7 秒超时，不跟随重定向。地址继续执行现有私网白名单与 DNS 校验。异常、超大或含无效 ID 的目录不导入部分内容。读取中断和超大响应同样记录失败及尝试时间，定时任务按配置间隔重试。租户模型总数上限仍为 200；超过上限时整批不导入。

同一个网关按上游模型 ID 去重。已有条目的能力、价格、名称、启停和功能绑定保持不变；上游已消失的模型也不会自动删除。新模型标为“待配置”，默认停用、无已确认能力。管理员编辑能力后再启用和绑定。`/models` 通常只提供 ID，不能据此断言模型具有图片、视频或语音能力。

权限和版本冲突继续沿用现有模型管理接口；读取目录时网关已被改动，导入会拒绝过期版本。目录检查按钮仍只检查，不执行导入。

## 图像与短剧使用真实网关

正常开发页面和发布构建中的图像创作、图像编辑工作区、短剧剧本、分镜与镜头制作均要求明确选择网关模型；未选择、未绑定、无权限或治理未就绪时禁用生成并显示原因。没有自动采用全局 `mock-svg`、`mock-text` 或旧组织模型的回退。历史模拟作品仍可浏览，手工剧本、分镜、素材上传、剪辑与版本恢复继续可用。短剧的剪辑页面也不再提供创建合成演示素材与时间轴的按钮；本地 MP4 剪辑合成本身仍保留，它不冒充模型生成。

组织管理员先保存网关地址与 API Key，确认/声明模型实际能力、启用模型、再保存功能绑定：

| 功能 | 必需能力 |
| --- | --- |
| 创意分析、剧本生成、分镜规划 | `text` |
| 图像创作、角色参考图、镜头图片 | `image` |
| 图片编辑及带参考图片的修改 | `image_edit` |
| 镜头视频 | `video` |
| 配音 | `speech` |
| 图片分析、跨镜头一致性检查 | `vision` |

模型名称和目录同步不能证明能力。DeepSeek 等文本模型不能仅因出现在网关目录中就用于图片或视频生成；须选择网关实际支持相应协议的模型。绑定中的“允许本次切换”决定是否可换用同能力的其他模型。

真实执行不再要求价格、费用上限、价格依据、报价、费用确认或预算，不创建新的费用预留，也不受旧账本的额度或未知费用记录阻止。页面选择已启用且能力匹配的模型后即可提交。实际费用由供应商结算；调用统计只保留次数、状态、耗时与上游报告的 token 用量，不将未知费用显示为免费。旧价格字段和费用记录保持兼容，费用记录在界面仅供查阅。

内容审核本轮默认暂时禁用：`CONTENT_MODERATION_MODE=disabled`或未设置时，不再要求审核器就绪；页面明确说明生成结果未经本项目自动审核，不伪造allow。只有显式设置`required`时才要求有效的`GATEWAY_MODERATION_*`或执行策略审核器，缺失或过期会拒绝启动。修改需重启API与worker，不改变上游网关的自身策略。权限、能力、来源授权、凭据和幂等保护继续生效，不恢复费用/额度门槛。

正式页面使用 `/gateway-tasks` 及项目下的 `gateway-generations`、`gateway-storyboard-generations`、`gateway-analysis`、`gateway-creative-jobs`。这些入口在服务端拒绝缺少网关模型的请求，并复用既有权限、功能绑定、幂等与 worker 执行链。旧接口保留给历史客户端及离线合成测试，正式页面不会在新接口失败后重试旧接口。

旧的界面回归设施显式以 Vite 的 `--mode legacy-fixtures` 启动，以继续验证合成任务的编辑、恢复和布局；这是仅开发服务器可用的测试配置，禁止以该模式执行发布构建。`playwright.gateway.config.ts` 使用正常模式，连接本地 HTTP 假供应商，覆盖真实网关请求、PNG 持久化、剧本/分镜能力路由和失败不回退；不使用真实服务凭据或付费调用。
