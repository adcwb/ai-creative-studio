# 后端配置与模型同步

系统设置新增“后端配置”，由部署环境中的 `STUDIO_ADMIN_EMAILS` 指定可登录管理的邮箱，逗号分隔。组织所有者和组织管理员不会自动获得全局配置权限。修改部署管理员列表需要在部署端修改环境变量并重启；接口继续要求登录、CSRF 和审计。

后端原先直接读取环境变量。本版增加私有 JSON 配置文件，默认是 `DATA_DIR/backend-config.json`，也可用 `STUDIO_CONFIG_FILE` 指定固定路径。API 与 worker 在初始化服务之前加载文件，文件中的值优先于环境变量。网页保存不会重启进程；页面显示待重启项目。独立 worker 应挂载相同文件，全部相关进程重启后生效。

表单覆盖 `backend/.env.example` 的配置项。`DATA_DIR`、`AUTH_MODE`、主密钥、配置文件位置和部署管理员由部署环境管理。其他字段可修改或恢复环境值。敏感项不回显，空白输入保留已有值，通过“清除值”显式清除；“恢复环境值”删除文件中的覆盖值。数据库与认证配置错误可能导致下次启动失败，此时由部署管理员修正私有文件或移除相应覆盖。

文件权限为 0600，目录为 0700。该配置文件与传统 `.env` 一样可包含数据库、SSO 等敏感配置，不应提交 Git 或公开下载。网关 API Key 仍使用 AES 加密后保存在模型存储中。配置文件由一个 API 实例负责写入；多 API 部署应将管理请求固定路由到该实例。worker 只读取。文件中的版本摘要用于拒绝过期保存。保存会同步文件及其所在目录；如果写入结果未确认，应重新读取版本再决定是否重试。

## 网关 API Key

文件模式首次启动且没有旧密文时，服务自动在 `DATA_DIR/model-config.key` 初始化随机 32 字节主密钥，并在重启时复用。密钥先完整写入私有临时文件再原子发布，不覆盖并发进程生成的文件。不能删除此文件后继续使用旧密文；应恢复原密钥。已有密文但没有主密钥时拒绝生成替代密钥。

`MODEL_CONFIG_KEK_BASE64` 的显式配置优先。也可通过 `MODEL_CONFIG_KEK_FILE` 指定共享私有文件。PostgreSQL 与独立 worker 不会各自生成默认密钥，必须显式提供同一个环境密钥或挂载同一密钥文件。新安装可初始化共享文件；已有加密数据必须使用原密钥，不能切换到全新密钥。已有密文时，缺失密钥或提供错误密钥都会导致 API 与 worker 启动失败；尚无密文的 PostgreSQL 实例仍可在未配置密钥时保存不含凭据的声明。

主密钥独立保管，不通过网页修改，也不包含在模型逻辑导出中。备份与恢复时保留原主密钥；轮换沿用已有离线轮换工具，完成后更新环境变量或密钥文件。不要把新密钥直接覆盖旧密钥来代替轮换。

## 模型目录同步

AI 网关列表和网关模型页提供“同步模型”。模型页先选择一个具体网关。编辑网关时可设置定时同步间隔，默认关闭；调度由 API 进程每分钟检查，不依赖网页保持打开。API 停止期间不执行同步，重启后继续按持久化的上次尝试时间判断。

同步只调用网关的 `GET /models`，不产生生成请求。完整目录最多 200 个条目、响应最多 1 MiB，7 秒超时，不跟随重定向。地址继续执行现有私网白名单与 DNS 校验。异常、超大或含无效 ID 的目录不导入部分内容。读取中断和超大响应同样记录失败及尝试时间，定时任务按配置间隔重试。租户模型总数上限仍为 200；超过上限时整批不导入。

同一个网关按上游模型 ID 去重。已有条目的能力、价格、名称、启停和功能绑定保持不变；上游已消失的模型也不会自动删除。新模型标为“待配置”，默认停用、无已确认能力及费用。管理员编辑能力与费用后再启用和绑定。`/models` 通常只提供 ID，不能据此断言模型具有图片、视频或语音能力。

权限和版本冲突继续沿用现有模型管理接口；读取目录时网关已被改动，导入会拒绝过期版本。目录检查按钮仍只检查，不执行导入。
