# 第六轮架构：可替换创作供应商与本地成片

实现基线为 `2ff0b9260471d3ac6b248ee8ce07e16b4cdf9447`。以实际代码与 [OpenAPI](../api/openapi.json) 为准，旧总架构描述不覆盖本轮实现。本轮只在本地提交与验证，不推送、部署、配置凭据或调用付费模型。真实协议的本地假服务测试不构成模型效果、账号权限或费用验证。

## 分阶段验收

1. 固定媒体与供应商边界、输入限制、来源标识和恢复规则。
2. 需求澄清、真实文本剧本/分镜协议、图像和音视频适配；默认继续无凭据模拟。
3. 角色参考、上传编辑、分镜媒体关联、历史恢复、镜头增删排序和可编辑时间轴。
4. 使用合成素材实际输出含音轨与字幕的 MP4；执行媒体探测、播放、API 与桌面/手机回归。

用户已指定多厂商兼容方向，具体模型、账号权限和预算尚未配置。默认协议仅是可替换适配边界，不能视为用户授权调用供应商。素材与生成记录必须保留自身来源，当前配置变化不能重新标记旧素材。角色参考与一致性提示不保证跨镜头身份一致；本地静态图转视频也不能冒充生成式视频模型。

## 数据归属与版本

沿用 FileStore 的 DATA_DIR、排他进程锁和项目快照。项目 `version` 控制需求、剧本、分镜与历史恢复；`script_version` 判断分镜来源过期。媒体有独立 `version`，用于时间轴与导出快照，不暗中增加剧本版本。媒体元数据与回执持久化到同目录 `media/state.json`，产物在专用子目录，由随机服务端 ID 寻址。

历史保存的是被替换的结构化稿件，不是生成尝试列表。恢复要求当前 `expected_version`、持久幂等键和无活动生成；先保存当前稿，再恢复所选稿。历史剧本恢复使剧本修订前进，不能倒拨当前版本消除分镜过期提示。备份和回退必须包含整个 DATA_DIR。

## 调用与安全边界

所有对象仍按公开演示 `space_id` 过滤；没有新增企业账户或计费系统。服务继续只供本地使用。项目 JSON 请求保留 64 KiB、严格类型/未知字段/null 校验；原图像请求保留原有限制。浏览器不接触凭据，客户端不提供任意供应商 URL；外部适配端点固定，不跟随重定向，不自动重试付费请求。

媒体上传不接受远程 URL、用户文件路径或可执行参数。服务端检查体积、真实媒体格式和尺寸/时长，文件名只作显示信息。FFmpeg 使用参数数组，不通过 shell；输入只能是受控本地资产，执行有超时及资源边界。上传或生成成功不等于被加入时间轴，时间轴明确引用资产并控制顺序、入点、长度、音量和字幕。

新的写请求先检查已接受回执，再检查当前版本和活动任务。网络响应不明时前端保留原键、原 body，不自动换键。远端 running 请求在进程恢复后不自动重发，因为中断或超时不证明上游未计费；真实模式显式再发可能再次收费。取消是本地停止意图，不能保证上游计费撤销。导出使用接受时的时间轴快照，失败保留此前已完成产物。

## 验证证据

API 合同检查使用临时二进制、临时 DATA_DIR 与回环端口，不继承模型凭据。独立验收验证原图像/剧本/分镜回归，以及上传限制、版本冲突、重复提交、恢复、取消、字幕音轨与导出。最终测试结果以本轮验证记录为准，本文件描述架构而不预先宣称测试通过。

## 媒体边界与本地输出

上传仅追加资产，因此不要求 `expected_version`，成功后媒体版本增加，原内容不会被覆盖；重复请求由含内容与标签的指纹去重。时间轴保存要求媒体版本，导出接受时要求版本并冻结快照，但不改变编辑版本。取消提交空 JSON 对象与幂等键。下载支持 HTTP Range，字幕另有 SRT 下载路径。

单文件上限 32 MiB；图片最多 8192×8192 且不超过 2000 万像素。时间轴支持 1–30 镜、单镜 0.5–30 秒、总长不超过 180 秒；音量 0–1，裁剪采用归一化坐标。每项目最多 120 素材和 30 导出，同时最多 2 个本地合成。上传标签最多 120 字，不允许 NUL/换行。FFprobe 与 FFmpeg 都仅允许 file/pipe 协议。媒体输出限制是 MVP 资源保护，不是用户计费系统。

媒体输出当前为 640×360、24fps、H.264 视频与 AAC 音轨。逐镜字幕按时间轴累计起止时间生成，MP4 内含 mov_text 软字幕并提供 SRT；播放器是否显示软字幕取决于播放器能力，不能把探测到字幕轨等同于浏览器已显示；前端另使用 `/subtitles.vtt` 的 WebVTT track 呈现预览字幕。配音不足镜头时长时补静音，过长时按镜头截断；背景音轨按成片长度循环与混音。此 MVP 不包含逐词强制对齐、音素口型同步或专业多轨剪辑。

官方供应商生态由显式 registry 描述原生协议、兼容协议与未实现能力，模型 ID 由服务端配置。列出品牌不等于所有能力均可调用；未实现或需要单独授权的能力必须返回不可用状态，不能退化为假成功。OpenAI、Anthropic Messages、Gemini generateContent 等原生结构独立适配，兼容协议与原生协议不得混称。实际支持矩阵以本轮产品文档及能力 API 为准。

## 新图像协议与参考图

Gemini 图像通过固定 `generativelanguage.googleapis.com` 的 `generateContent` 原生结构发送文本与可选 `inlineData` 参考图，使用响应 `inlineData`，不读取远端 URL。[GenerateContent 官方字段](https://ai.google.dev/api/generate-content) 包含 `responseModalities` 和 `imageConfig`。较新的模型可能采用其他接口；配置模型 ID 不代表全部 Gemini/Nano Banana 型号都支持此协议。

Ark 图像通过固定 `ark.cn-beijing.volces.com/api/v3/images/generations`，要求 `response_format=b64_json`、2K 单图输出、保留水印；参考图为本地图片的 data URI。[Seedream 官方协议](https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh) 将图像原生字段与 Chat Completions 区分。适配器接受 PNG/JPEG，按实际尺寸校验后规范化为 PNG；压缩输入/最终 PNG 最大 16 MiB、总像素 2000 万，拒绝非图像、MIME 冒充、多结果、仅URL响应和重定向。构造器不接受用户端点；HTTP假服务注入仅用于包内测试。

`reference_asset_id` 指向同项目本地上传的参考图。此能力提供模型输入约束，不能保证人物身份、服装、姿势或跨镜头外观一致；不支持参考图的供应商必须拒绝该操作。照片本地裁剪与模型参考编辑分别记录，不将本地裁剪宣称模型编辑。

## 创作任务恢复与限额

独立 `creative.json` 保存需求分析、图像、配音和视频任务及回执。分析也返回异步任务，而非直接同步分析对象；列表轮询获得结构化问题与建议。创作任务记录接受时的项目版本、需求快照、供应商、镜头和参考图关联。它不自动覆盖项目需求；用户将澄清答案保存到需求后再生成。

每项目最多一个活动创作任务，全局最多四个；创作任务每小时最多二十个，总计五百条任务及一千条回执。剧本与分镜真实调用另有合计每小时二十次限制，包括失败尝试。此限额降低误触与重发风险，不是供应商预算或金额担保。`expected_provider` 与 `expected_model` 在真实模式必须同时匹配已确认的服务端配置。剧本、分镜与创作任务接受时持久化 `model`；旧模拟记录允许省略。排队与恢复须复核冻结的供应商和模型，配置变更不得把旧任务悄悄发送给同供应商的新模型。

视频提交后先持久化供应商任务 ID，再只读查询并下载。已有上游 ID 的任务可在中断后恢复查询；没有持久 ID 的中断不能重新提交生成。`resume` 只接受已有 ID 的失败/取消视频并重新排队查询，不发送新的生成 POST。取消仅停止本地等待，供应商可能继续执行及计费；再次新建任务仍可能再次计费。
