# 第二轮协作与交付范围

本轮从已发布并通过 CI 的 `7284fab759ee6f59d1e75ab1b1c1dc13b34fba58` 延续。开始时本地工作树干净，远端 `master` 与该提交一致，未发现新增用户改动。所有工作在同一个指定云开发环境进行。

## 实际分工

本轮确实启动了五个职责独立的子代理，均使用 xhigh 推理强度；并非仅以五种角色口吻描述同一份工作。主代理负责范围集成、跨角色反馈、最终审查、文档及发布边界。

| 角色 | 职责 | 文件所有权 |
| --- | --- | --- |
| 产品 | 收敛用户路径、范围、可测试验收标准 | `docs/iteration-2-product.md` |
| 架构 | 契约、兼容、幂等、状态、演示安全边界 | `api/openapi.json`、`docs/iteration-2-architecture.md` |
| 前端 | 接入真实业务 API，统一组件、tokens 和原创品牌资产 | `frontend/src/` 非测试文件、`frontend/public/`、`frontend/index.html`、`docs/brand.md` |
| 后端 | 模板目录、参数、真实重试调度/关联、持久化素材查询、Eino 流程 | `backend/` Go 非测试文件 |
| 测试 | 独立审查、后端及 UI→API→数据验证、回归和实际浏览器截图 | Go/TS 测试、`frontend/e2e/`、`scripts/smoke.py`、`docs/iteration-2-verification.md` |

产品与架构先对齐契约，前后端随后并行实现；测试角色独立发现问题并交回对应实现者修复。主代理整合 README、通用架构说明及选定截图，避免多个角色覆盖同一文件。

## 最终范围

- 模板目录来自后端：海报、肖像概念、通用图像；比例与风格选项也由后端提供。
- 参数由后端校验并真实传入 Eino 模拟流程，SVG 比例/视觉随参数变化；不宣称真实模型能力。
- 任务详情由详情 API 读取。
- 失败任务经专用重试 API 创建新任务，持久化 `retry_of`、保留失败原件，支持幂等重放并真实调度。
- 素材关键词及类型筛选由后端查询持久化数据，不能以页面内过滤冒充业务实现。
- 保留映创品牌，统一可访问的桌面/移动组件、Logo、字标、favicon 和设计 tokens。

不增加真实付费模型、图像上传编辑、短剧生成、取消执行中的任务、生产身份认证或企业隔离。关闭详情和取消编辑只作用于当前交互，不冒充服务端任务取消。

## 发布边界

第二轮只修改并验证云工作区；上一轮推送授权不自动延伸至本轮。本轮不推送、不创建 PR、不部署、不更改仓库可见性，等待单独发布授权。Library 此前初始化网络失败，不反复尝试附件上传；截图保存在工作区供后续获准的交付使用。
