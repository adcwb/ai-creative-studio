# 第六轮角色协作

本轮按用户明确要求分工，所有角色共享 `/workspace/ai-creative-studio`，从发布基线 `2ff0b9260471d3ac6b248ee8ce07e16b4cdf9447` 开始。初始云环境仍是第四轮提交，主代理只读获取远端后快进到指定基线，未推送。

| 角色 | 实际代理 | 文件与职责边界 |
| --- | --- | --- |
| 集成负责人 | `/root` | 总体编排、阶段推进、历史回滚实现、集成修复与最终验收 |
| 产品 | `/root/product` | 本轮产品/协作文档、README及下一轮交接；后续按集成安排补位原生Anthropic/Gemini与MiniMax文本适配及fake上游测试；核对限制，不替独立测试背书 |
| 架构 | `/root/architecture` | API契约、媒体与供应商边界、恢复和成本风险说明 |
| 前端 | `/root/frontend` | `frontend/src`：既有品牌下的新创作、素材、时间轴和导出界面 |
| 媒体后端 | `/root/backend_media` | 媒体资产、上传验证、关联、时间轴、FFmpeg合成、导出与取消 |
| 创作后端 | `/root/backend_ai` | 文本/图像/视频/语音协议适配、输出校验、恢复和外部请求保护 |
| 独立测试 | `/root/qa` | 工具链、回归和新功能故障/恢复/E2E/媒体探测/播放验证及证据记录 |

代理先读最小必要上下文，按接口消息协同，避免重复读取所有历史轮次。共享文件变更需先协调；各角色仅提交自己的文件，由集成负责人检查最终工作树和全量测试。并行实施不等于并行变更账户、网络或权限；所有角色遵守无凭据、无付费、无部署、无推送边界。

阶段验收见 [产品范围](iteration-6-product.md)。独立测试报告的合成演示与模拟上游证据只证明实现和协议处理，不能证明真实模型效果、身份一致性或费用。
