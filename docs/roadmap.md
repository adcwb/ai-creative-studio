# 产品路线与能力边界

此文件从既有 `architecture.md` 后续适配路径整理，区分可运行能力与尚未交付的方向。

| 阶段 | 范围 | 状态 |
| --- | --- | --- |
| 第一轮 | 图像任务、Eino mock SVG、进度、素材保存及文件持久化 | 已交付 |
| 第二轮 | 图像模板/参数、关联重试、任务详情、素材筛选、映创品牌 | 已交付 |
| 第三轮 | 固定官方 OpenAI Images 协议、PNG 安全保存、模式保护、桌面对齐 | 已交付；仅本地假上游验证真实协议，不代表模型质量或账号验证 |
| 第四轮 | 短剧项目、需求管理、结构化模拟剧本、编辑保存 | 本地实现与验证通过；尚未发布 |
| 后续创作 | 分镜、角色一致性资产、音视频生成与合成 | 尚未实现，需分轮定义完整业务闭环 |
| 生产基础 | PostgreSQL/对象存储/独立 worker、认证授权、用量和内容安全 | 仅预留设计，不构成已交付生产能力 |

第四轮只提供单集草稿：两个固定角色、三个场景，明确标记为程序模拟文本。可编辑内容并保存当前版本；生成失败保留旧稿，版本冲突不得静默覆盖。不提供删除、剧本多版本浏览、真实文本模型、分镜图像、配音、视频或导出成片。

下一轮范围需结合本轮验收与用户选择确定。真实模型接入前应独立评估凭据安全配置、数据发送授权、预算及失败计费风险；配置存在不等于模型结果已验证。公开 GitHub 源码不等于应用获准公开部署。
