# 第十轮：编辑器、海报与社交发布

基线：`b6b3d83f56c90175af03bb3dd0e3db24a20caefd`。本轮授权为本地开发、合成测试与提交；不包括推送、镜像发布、应用部署、真实 OAuth、实际社交发布或付费模型。验收结果见[独立验证](iteration-10-verification.md)，不能用基线 CI 成绩替代。

## 交付矩阵

| 请求 | 本轮实现 | 验证与界限 |
| --- | --- | --- |
| 实时画面预览 | canvas 播放／拖动、按素材时间寻帧、镜头／叠层合成 | 低清静音；浏览器寻帧、字体和转场边缘可能不同，最终文件权威 |
| 非线性编辑扩展 | 排序、复制、播放头拆分、逐镜裁剪，叠层与音轨定位 | 仍为顺序主镜头＋有限叠层，不是任意轨道专业 NLE；带镜内配音须先移至独立音轨再拆分 |
| 持久化关键帧 | 每画面层最多16个位置／透明度关键帧，线性插值与端点保持 | 服务端校验、CAS、重启保存、实际导出运动／透明度像素；不含缩放／旋转曲线 |
| 可组合转场 | 原有黑场／溶解，加左右擦除、左右推移、圆形展开 | 逐镜选择；音频与字幕共用重叠后的时间轴；不接收任意过滤表达式 |
| 4K | 2160p，横3840×2160／竖2160×3840／方2160×2160，24fps，最长15秒 | 三种画幅实际编码及解码；不承诺长片、HDR、无损或实时4K |
| 海报文字与Logo | 最多12层，文字／图片位置、大小、透明度与层次，保存和新PNG导出 | 最多2048×2048，实际像素、幂等、重启、跨租户；字体预览有差异 |
| TikTok | 审批门控、OAuth连接、创作者能力、视频直发／草稿上传、查询恢复 | 合成上游验证；真实审批、授权与发布未执行。照片、自动refresh及webhook不在已交付视频链路内 |
| 抖音 | 经审批的H5分享协议、受控素材交接、官方 client_token→ticket 获取与加密共享缓存／到期刷新 | 交接不能证明App打开或最终发布；实际客户端和应用审批未验证；企业服务端代发未实现 |
| 小红书 | 真实受控素材导出、用户主动复制本地文案，不预填笔记标题／正文／话题 | 官方接入暂停；无通用服务器直发；已有资质SDK运行时尚未实现 |
| 中英文 | 新UI文案、错误／空态／ARIA；README互链 | 语言与币种独立，只宣称简中／英文 |

具体社交配置、状态和未实现协议以[社交文档](iteration-10-social.md)及[抖音H5运行时](douyin-handoff.md)为准。官方依据汇总见[平台合同](social-platform-contracts.md)。[媒体合同](iteration-10-media.md)和[海报合同](iteration-10-posters.md)记录资源上限、格式和回滚风险。

## 数据与迁移

媒体状态增加可选 `poster`、`social` 和叠层 `keyframes`；旧状态默认保持旧行为。文件存储仍备份整个 DATA_DIR；PostgreSQL继续使用现有事务与媒体JSON记录，无新增数据库服务。新的私密社交token以独立部署KEK加密保存，公开状态不包含密文或token。抖音应用级缓存也保存在私密媒体回执中，同一应用的多实例必须共享同一 PostgreSQL 状态和密钥，不能在独立测试／生产缓存中复用真实应用凭据。不要把真实凭据放入源代码、截图、报告或环境示例。

旧二进制可能忽略新增字段，不能直接回滚并继续编辑。回滚需要停写、匹配版本全量备份与独立保存的部署密钥。更新旧业务数据前应演练恢复，不将单个state.json视为完整备份。

## 外部待验证与本地余项

真实社交应用审批、OAuth、账户权限、发布结果和移动App行为均未执行。远端内容必须经过用户主动确认和平台能力门控；未知创建结果不能盲目重发。平台账号及凭据配置不因开发授权自动获准。

真实模型账号、质量／费用、离线模型权重推理、合格S3服务互操作仍延续上一轮未验证状态。新增编辑器与本地导出不依赖这些外部条件。厂商模型预算 USD3 与CNY5未使用，也不适用于社交服务。

本轮不实现所有行业软件特性：多机位、任意视频轨道、复杂合成表达式、HDR／色彩管理、自动强制对齐质量保证、商用口型保证均不在已验证能力内。社交照片发帖、自动刷新令牌／webhook、抖音企业代发与小红书SDK仍需后续实现及真实审批；不能把接口存在称为已发布。
