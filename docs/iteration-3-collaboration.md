# 第三轮范围与协作

基线为已发布并通过 CI 的 `6e30ff60c4675a7d6ea2a4859dbc2e244bb1bab5`。开始时本地工作树干净，远端一致；全部工作继续在同一云环境进行。本轮仅本地实现、验证与提交，未授权推送、PR 或部署。

## 计划与验收

1. 修复可复现的桌面底部不齐：左右创作面板自然拉伸对齐，侧栏背景覆盖长页面；不以固定高度或裁切掩盖溢出。检查多个桌面宽度、手机、长文本、空列表及失败编辑状态，保存几何与真实截图证据。
2. 增加一种明确的官方图像 Provider 协议适配，保留默认 mock。提供不含凭据的运行模式/配置状态，参数由后端校验；历史任务与素材保留各自真实来源。
3. 真实图片经字节数、格式和尺寸校验后安全落盘；只处理 base64 PNG，不下载供应商或用户 URL。Eino 继续参与规范化与 provider 执行。
4. 真实请求不自动重试；执行中断不得通过重启静默重复可能收费的请求。显式重试保留关联、幂等和费用不确定提示。
5. 使用本地 HTTP 假服务完成协议、错误、超时、图片、恢复和前后端联调测试，不创建或获取凭据，不进行真实付费生成，不声称已验证模型质量。

接口及供应商字段在产品/架构对齐后冻结；不扩展数据库迁移、认证、计费或视频功能。

冻结决定：官方 OpenAI Images `POST /v1/images/generations`，固定 `gpt-image-2-2026-04-21`，不提供任意 base URL。`GET /api/v1/capabilities` 公开安全模式/本地配置状态，不能视为远端凭据验证。PNG 与 JSON 分别限 16MiB / 24MiB，图片实际尺寸必须匹配所选比例对应尺寸。真实 `running` 重启转失败并标明执行结果不确定；新提交在不可用配置下返回503，但原已接受请求仍按其幂等记录重放。生产启动不增加假服务开关，测试通过 Go 测试专用构造器/harness 注入本地上游。

集成审查补充：前端在能力未知或不可用时完全暂停创建/重试 POST，保留原草稿与幂等键，待能力恢复后由用户明确再提交。为防止旧页面显示 mock、服务端已切换 real 的意外调用，前端提交成对 `expected_provider` / `expected_model`；仓库锁内先匹配已接受幂等请求，新请求再核对当前配置，模式不符返回409，不入队。前端刷新状态并要求再次点击，不自动重发。旧 API 调用两字段均省略仍兼容；该保护不替代生产认证或费用控制。

## 集成收尾

独立审查发现旧快照恢复会用新库默认字段掩盖缺失字段，可能静默遗失幂等记录；现改为已有文件解码零值结构，缺失必要字段拒启并保留原字节。7 种缺失/null 场景回归与最终竞态检查通过。

最终布局 24 个状态均通过，双列底边及侧栏/页面底边最大差均为 0 CSS px。修复前后截图、几何 JSON 与本地协议调用摘要保存在 `docs/screenshots/`；仅为合成演示数据。完整检查与未验证边界以 [独立验证记录](iteration-3-verification.md) 为准。新增检查已接入 CI 配置，但本轮未推送，因此未执行远程 CI。
